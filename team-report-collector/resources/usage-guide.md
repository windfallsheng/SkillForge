# 团队日报收集使用指南

## 能做什么

把团队成员的日报收进一个本地收集台：口述/文件批量/页面导入三种方式进数据 → 产出三件套——`team-report.html` 单文件收集台（离线双击可开，表单填写 + 主题切换 + 导出/导入 JSON）、`reports.json` 数据真相源、`summary.md` 按日期分组的汇总报告。

## 怎么用

1. 说「**收日报**」或「**收集团队日报**」→ 我读配置、开始收集
2. 直接口述：「张三：今日做了 A，明日做 B；李四：…」；或给 md/txt/csv/xlsx 文件批量导
3. 我产出三件套并打开收集台 → 成员在收集台页面补填 → 点「导出 JSON」发回 → 我帮你并入真相源
4. 汇总 md 按日期分组，风险集中项单独聚合，一眼看清谁没报、谁有阻塞

## 可改配置（user-config.md）

- `TEAM` / `TITLE`：收集台标题
- `DIR`：落盘目录（默认 reports-collector/）
- `THEME`：dark 深夜青绿 / light 浅色纸张
- `REPORT_DATE`：汇总目标日期

## 使用提示

- 收集台完全离线可用，页面填写的数据存浏览器本地，导出 JSON 才会落成文件
- 多份收集台各自独立（内嵌 ID 隔离），互不串台
- 同一成员同一天多条日报自动合并
