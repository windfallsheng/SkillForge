# 收集台 HTML 版式（五主题令牌 + 科技感背景层，与日报/周报同体系）

## 版式总览

- 五主题令牌：tech（深蓝科技，默认）/ biz（浅色商务）/ mono（IDEA 黑亮）/ light（IDEA 白亮）/ warm（温暖渐变），色值与 daily-report 同一套 12 核心契约（另含收集台扩展 --panel2 列表条目底、--input-bg 表单输入底）；`html[data-theme]` 运行时切换；右上角换肤坞五色点随点随换、localStorage 记忆（键 `trc:<ID>-theme`，ID = 页内嵌 trc-id meta，多份产物互不串台、改名/移动目录记忆不丢）
- 字体全用系统本地字体栈（ui-monospace/'SF Mono'/SFMono-Regular/Menlo/Consolas/system-ui，品牌字体 PingFang/YaHei/apple-system 零出现），禁止 CDN、@import、外链 CSS/JS/图片/网络字体——页面离线双击可开
- 三张卡：标题卡（团队名 + 日期徽章 + 统计三数：成员数/日报条数/风险条数）+ 表单卡（姓名/日期/进展/计划/风险五字段 + 保存按钮）+ 汇总列表卡（按日期分组的成员条目 + 导出 JSON / 导入 JSON 按钮）
- 多文件隔离（必植）：头部写 `<meta name="trc-id" content="<UUID>">`（crypto.randomUUID() 标准 UUID v4）；localStorage 键一律 `trc:<ID>-xxx`（xxx 为具体用途后缀 theme/reports），禁止裸通用键名；页面 JS 启动时校验 id meta——非法或缺失（占位残留/手写变体/误沿用旧值）时按路径键（`'sf-heal:' + location.pathname`）自愈为 crypto.randomUUID() 标准 v4 并回写 meta，console.warn 显性报警；路径键持久化保证同文件跨打开稳定复用；合法 UUID 原样放行
- 版本戳：`<meta name="sf-template" content="team-report-collector@1">`（模板升级递增 @N）
- 入场动画：三张卡错峰上浮淡入（标题 0s/表单 0.13s/列表 0.26s）；卡片入场动画 fill-mode 必须用 backwards 严禁 both（both 使动画结束帧覆盖 hover transform）；滚动入场用 IntersectionObserver + 2s 兜底 setTimeout 强制全显（headless 截图 / 打印预览 / PDF 导出环境卡片不得永久隐藏）
- 科技感背景层四件套（与日报/周报同款）：SVG 微噪点（opacity .04，mono 退隐）+ 60px 网格底纹 + 星点（biz/light/warm 退隐 .28、mono 灰白化）+ 全屏扫描线 + 循环光带；容器 .wrap 宽 clamp(640px, 60%, 1200px)（移动端 100%）；卡片面板实色 + 8px 水平条纹 + 上下高光线 + 圆角 6px + 卡阴影；头部卡含光晕呼吸（.card-glow）与四边扫描线（.scanline-el）；标题渐变文字（--title-grad）+ 光晕
- ?shot 截图模式：页面 JS 检测 location.search 含 shot 时给 html 挂 data-shot 属性（CSS 关闭入场动画直接终态，headless 虚拟时间下动画帧不推进会停在初始帧导致截图空白）、强制全部卡片 opacity 1、隐藏换肤坞，body 四周 padding 统一 40px，供主体内容截图
- 页脚 10px muted 文字，署名固定 GENERATED BY AI TEAM（禁止真实团队名/项目名）

## 数据流（TRC_DATA）

- `window.TRC_DATA`：生成时内嵌的初始数据数组（字段 name/date/progress/plan/risk，JSON 序列化注意转义）；页面启动时优先读 localStorage `trc:<ID>-reports`，有则覆盖初始数组展示
- 页面「保存」：表单提交 → 追加/合并进本地数组（同 name+date 合并）→ 写 localStorage
- 「导出 JSON」：Blob 下载 reports.json（含本地最新数据）；「导入 JSON」：file input 读 json 合并进本地数组
- 渲染：按 date 分组倒序、组内按 name 排序；每条显示进展/计划/风险三行（风险空则不显该行），风险行强调色标
