# 会议纪要使用指南

## 能干什么

把一场会整理成五段式会议纪要：会议信息（主题/日期/地点/主持人/参会人）/ 会议结论（一句话 TL;DR + 核心决策）/ 议题讨论（议题名 + 结论 + 讨论要点）/ 决议与行动项（事项 + 负责人 + 截止时间）/ 下次会议。适配各行业各类型会议：内置 12 类会议类型词典（周例会/评审会/复盘会/客户会议等），报会议类型自动换要素侧重与行动项话术。行动项带负责人与截止时间，是汇报链的源头——日报/周报/月报/季报生成时可直接引用会议行动项。

## 基本用法
- 直接说「写会议纪要 / 记一下会议 / 整理会议记录」→ 默认按当前会话口述与提供的材料生成
- 指定会议（多种说法均可）：
  - 「今天的会 / 刚才的会」→ 当天会议（日期按当前系统日期）
  - 「昨天的会 / 上周三的周例会」→ 按口述日期换算
  - 「整理 2026-11-11 的会议纪要」→ 明确指定日期（若当天有多场会，按主题区分文件名）
- 同一场会议重复生成默认直接覆盖；说「保留之前的 / 另存 / 不覆盖」→ 文件名追加时间戳另存不覆盖
- 说「打开 / 查看 11-11 的会议纪要」→ 该纪要文件已存在时直接打开不重新生成；不存在则按正常流程生成

## 口头补充素材
- 说「补充一下：会上还定了月底上线，小明负责联调」→ 自动拆成行动项（事项 + 负责人 + 截止时间）并入行动项段
- 拆分信号：负责人词（XX 负责/XX 跟进/交给 XX）、时间词（这周/月底/周五前/11-20）、连接词（还有/另外/以及）
- 补充内容带分段词时按段并入：「议题：预算审批」→ 议题讨论段；「决策：走方案 B」→ 会议结论段；不带分段词按语义归段
- 与已记录内容自动去重，同一行动项只保留一条

## 贴文字 / 发图片 / 给文件整理
- 直接贴一段文字说「整理成会议纪要 / 把这段聊天记录整理成纪要」→ 以文字为主源生成；说「只整理这段文字 / 只按这段」同样跳过其它来源与会话上下文
- 发图片（白板照片/聊天截图/议程照片等 jpg/png/webp）或给文件（md/txt/docx/pdf 等）说「整理成会议纪要」→ 先用 Read 读取：图片按视觉理解提取文字信息，md/txt 直接读文本，docx/pdf 优先尝试 pandoc 转文本（无 pandoc 则请用户粘贴文字）；会议录音/视频不能直接解析，请提供转写文本或口述要点
- 图片模糊/内容读不清时：先把已提取的部分展示给用户确认或补充，不瞎编没读到的内容
- 素材不足的段写「暂无」并提示用户可补充素材
- 默认直接生成落盘（CONFIRM: never，无需确认）；把顶部 CONFIRM 改为 text/always，或临时说「先看看效果/先出效果」→ 先在对话输出整理好的纪要正文，用户说「可以/确认/落盘」→ 再落盘文件与内容区截图并开 html；说「改一下 xxx」→ 按意见修改后重新出效果再确认
- 说「不用确认/直接落盘」→ 当次跳过确认直接落盘（临时要求优先于配置）
- 说「不落盘/别写文件」时跳过确认，直接对话输出

## 自定义模板（适配各类会议）
- 内置模板为五段式（会议信息/会议结论/议题讨论/决议与行动项/下次会议），适合通用会议；特殊会议可自定义模板
- 临时换模板：说「这次按 xxx 来」→ 口头描述结构（如「按三段：会议结论/行动项/下次会议」），当次按该结构生成，不改配置
- 永久换模板：把顶部配置 TEMPLATE 改为 custom，并按 user-config.md 的「📝 自定义模板」节说明修改段结构，之后默认按新模板生成
- 说「以后都用这个模板」→ 自动把当前口述的结构写入「📝 自定义模板」节并把 TEMPLATE 改为 custom
- 模板优先于纯文字模式的信号词归类：指定了段名后，文字按段名归类填充

## 角色定制（我的职业画像）
- 默认按顶部「默认配置」ROLE 推断会议类型与术语（当前：全栈开发工程师（企业内技术开发））；说「我的职业是 XX / 我的主要工作是 XX / 以后默认用 XX 角色」→ 永久修改 ROLE
- 说「以 XX 的身份记」→ 当次按该角色视角生成（内置 12 类会议词条：周例会/项目评审/需求评审/技术方案评审/复盘会/客户会议/跨部门协调会/OKR 对齐会/全员会/设计评审/合同谈判/面试复盘可直接用），不改配置
- 词典外会议类型走兜底：按骨架 + 你提供的素材现场生成侧重；说「记住这类会」→ 固化为新词条

## 控制落盘（临时要求，仅对当次生效）
- 默认：对话输出 Markdown + md/txt/html 三文件 + 内容区截图 content-png 落盘到 DIR（auto 按系统选：macOS=~/reports、Windows=%USERPROFILE%\reports，模板默认值，路径以 user-config.md 顶部「默认配置」为准）/meetings/{系列名}/（SERIES_GROUP=auto：提取到稳定系列名建系列目录，未提取到回退 meetings/YYYY-MM/ 月份平铺）+ html 自动打开（DIR 目录/盘符不存在时自动改用用户主目录下 reports：macOS=~/reports、Windows=%USERPROFILE%\reports）
- 说「写到桌面」→ 本次落盘到桌面（macOS=~/Desktop、Windows=%USERPROFILE%\Desktop）；说「存到 ~/report / D:\report」→ 本次用指定目录（仍按 SERIES_GROUP 规则建系列/月份子目录）；说「这个系列叫 XX」→ 当次用新系列名建目录；说「以后这个系列叫 XX」→ 永久记住该系列名；说「把我旧纪要按系列整理」→ 一次性把 meetings/ 下旧纪要按系列名归置到系列目录
- 说「不落盘/别写文件」→ 本次只在对话输出，不写文件、不开浏览器
- 说「只要 md」「只出 html」「只要内容区截图」→ 本次只落指定格式文件；说「这次不截图」→ 本次跳过截图（content-png = 五张分节卡片整体一张图，四周约 40px 留白，不含头部标题、复制按钮、页脚）
- 说「只要截图/重新截个图」（如「给 11-11 会议纪要截个图」）→ 本次不重新生成内容，只对现有 html 执行内容区截图（覆盖 content-png，需 html 已存在，找不到则提示先生成）
- 说「别开浏览器」→ 本次落盘后不自动打开 html
- 说「保留之前的」→ 同一会议重复生成时不覆盖，文件名追加时间戳另存

## 配置开关（改 user-config.md 顶部「默认配置」节，长期生效）
| 配置项 | 作用 | 可选值 / 示例 |
|---|---|---|
| DISK | 是否落盘写文件 | true（落盘，默认）/ false（默认只在对话输出） |
| FORMATS | 落盘哪些格式（数组） | [md, txt, html, content-png]（默认，含内容区截图）/ [md, html] / [md, txt, html]（不截图）；content-png = 五张分节卡片整体截图（四周约 40px 留白），不含头部标题/复制按钮/页脚 |
| DIR | 落盘根目录 | auto（按当前系统自动选 DIR_MAC / DIR_WIN，默认）；DIR_MAC = macOS 根目录（模板默认 ~/reports，可改）；DIR_WIN = Windows 根目录（模板默认 %USERPROFILE%\reports，可改） |
| OPEN_HTML | 落盘后是否自动打开 html | true（自动打开，默认）/ false（不打开） |
| TEMPLATE | 纪要模板 | default（内置五段式，默认）/ custom（按「📝 自定义模板」节的结构生成） |
| ROLE | 默认职业角色画像 | 全栈开发工程师（企业内技术开发）等；职业名 + 括号内工作内容 |
| CONFIRM | 落盘前先出效果确认 | never（直接生成不确认，默认）/ text（纯文字整理模式确认）/ always（所有生成都确认） |
- 优先级：临时口头要求（不落盘/写到桌面/只要 md/只要内容区截图/这次不截图/别开浏览器/临时换模板等）永远优先于默认配置，仅对当次生效、不改配置
- DIR（按系统解析）指向的目录/盘符不存在时，自动回退到用户主目录下 reports（macOS=~/reports、Windows=%USERPROFILE%\reports）
