# 会议类型词典

五段式骨架对所有会议通用，只有「要素侧重 / 议题侧重 / 行动项模板」随会议类型切换。用户话术中声明会议类型即按词典取侧（如「整理昨天项目评审会的纪要」→ 项目评审词条）；未提类型按 ROLE 画像推断，推断不出用通用模板。

| 类型 | 信息头侧重 | 议题侧重 | 行动项模板 |
|---|---|---|---|
| 周例会 | 主持人 + 参会人 + 上周回顾 | 各人上周进度/本周计划/风险阻塞 | 「XX 跟进 YY 修复，负责人：张三，截止 2026-11-14」 |
| 项目评审 | 评审人 + 被评审人 + 里程碑节点 | 方案取舍/风险识别/评审结论（通过/有条件通过/不通过）| 「XX 按评审意见修订方案，负责人：张三，截止 …」 |
| 需求评审 | 产品 + 研发 + 测试三方 | 需求范围确认/边界与例外/优先级 | 「XX 需求补充验收标准，负责人：张三，截止 …」 |
| 技术方案评审 | 方案主讲人 + 评审组 | 架构选型/技术债/性能与安全 | 「XX 方案补充压测数据，负责人：张三，截止 …」 |
| 复盘会 | 复盘对象（项目/事故/活动）| 目标回顾/结果对比/根因分析/改进措施 | 「XX 输出复盘文档并同步全组，负责人：张三，截止 …」 |
| 客户会议 | 客户方 + 我方参会人 | 客户诉求/交付承诺/合同与回款 | 「XX 客户诉求 48 小时内书面回复，负责人：张三，截止 …」 |
| 跨部门协调会 | 各部门代表 | 职责边界/接口约定/时间对齐 | 「XX 部门确认接口字段，负责人：张三，截止 …」 |
| OKR 对齐会 | 各团队负责人 | 目标对齐/关键结果/依赖排期 | 「XX 团队输出 OKR 拆解表，负责人：张三，截止 …」 |
| 全员会 | 主讲人 + 发布事项 | 公司动态/政策宣贯/表彰 | 「XX 同步宣讲材料到全员群，负责人：张三，截止 …」 |
| 设计评审 | 设计师 + 产品 + 研发 | 视觉规范/交互流程/走查问题 | 「XX 按意见修改设计稿 V2，负责人：张三，截止 …」 |
| 合同谈判 | 双方谈判人 | 条款分歧/让步底线/签约时间 | 「XX 修订合同第 N 条并发对方确认，负责人：张三，截止 …」 |
| 面试复盘 | 面试官 + HR | 候选人评价/录用建议/薪资范围 | 「XX 推进背调与 Offer 流程，负责人：张三，截止 …」 |

- 通用模板（类型不明）：要素侧重 = 主题/日期/参会人；议题侧重 = 议程顺序；行动项模板 = 「XX 事项，负责人：张三，截止 YYYY-MM-DD」
- 触发：话术含类型词（周例会/例会/评审/复盘/客户会/协调会/对齐会/全员会/谈判/面试等）→ 信息头侧重、议题侧重、行动项话术全部按该词典词条生成
- 临时指定：说「按项目评审会的格式记」→ 当次按该词条生成，不改配置
- 兜底：词典外的会议类型（读书会/培训会/家长会等）→ 骨架 + 用户素材现场生成侧重，本次生效；说「记住这类会」→ 固化为新词条
- 会议类型只换要素侧重与行动项模板，五段骨架/HTML 样式/落盘规范全部不变；优先级：临时指定 > 话术类型词 > ROLE 画像推断 > 通用模板
