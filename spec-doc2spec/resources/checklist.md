# AI 校对清单（机械转换后必做）

Pandoc 机械产物只作底稿。AI 必须 Read 源文档与 00-converted.md / 00-plain.txt，逐段对照核对，发现问题直接在底稿上修正，修正后再进入需求加工。

## 量化校验断言（机器计数，先跑）

- 图片：`grep -o '!\[' 00-converted.md | wc -l` == IMG_DIR 下图片文件数（拍平转 PNG 后）；不等则逐个排查丢图/多图
- 章节：`grep -c '^#' 00-converted.md` 的标题数与 Read 源文档数出的章节数一致；缺则定位丢失段落
- 双通道量比：`pandoc 00-converted.md -t plain | wc -c` 与 `wc -c 00-plain.txt` 字符量差 ≤5%（超出说明 gfm 版有格式残留或内容丢失，逐段比对找回）

## 完整性核对

- 章节结构：源文档每个一级/二级标题在转换结果中都有对应内容，无整章整段丢失
- 双通道比对：00-plain.txt 是纯文本全量输出——若某段内容 plain 版有而 gfm 版无，说明该段在格式转换中丢失（常见于 Word 文本框、SmartArt、批注框内文本），必须找回补进底稿
- 关键词抽查：源文档高频词/专有名词（功能名、接口名、字段名、编号）逐一 grep 底稿确认在位

## 错误排查（Pandoc 已知局限）

- **表格**：合并单元格拆裂、列错位、跨页表格断行错乱 → AI 重建为规范 markdown 表格（合并单元格用行内注释注明合并范围）；表格被降级成纯文本段落时恢复为表格
- **列表**：多层嵌套层级丢失、有序列表编号中断 → AI 按原文恢复层级与编号
- **图片**：引用路径失效、图片丢失、.emf/.wmf 引用 → 见 images.md
- **嵌入对象**：Word 内嵌 Excel 表格 / OLE 公式对象不随 Pandoc 提取 → 双通道比对发现缺失后，提示用户「嵌入对象需单独导出」，或从源文档截取对应内容补进底稿并注明出处
- **特殊字符**：公式变形、箭头/全角符号乱码 → AI 修正；数学公式用 $...$ 行内 / $$...$$ 块级保留 LaTeX 原貌
- **修订痕**：Word 修订模式未接受时，转换可能残留删除线文本 → 提示用户「接受所有修订」后重转；无法重转时 AI 按「接受后状态」处理并注明
- **页眉页脚/页码**：转换为正文残留文本 → 剔除
- **超链接**：链接地址丢失 → AI 从源文档补回或注明

## 校对纪律

- 修正直接在 00-converted.md 上进行，修正后该文件即「已校对底稿」
- 修正与补漏逐条记录（供最终报告引用）
- 校对后仍存疑的内容进 _clarify.md 澄清清单，不臆造
