# doc2spec 使用指南

## 能干什么

把 Word / PDF / Markdown 文档转成高质量结构化 Markdown：Pandoc 机械转换 + AI 逐段校对（量化校验 + 双通道比对纠错补漏）+ 整理成干净正文稿。图片自动提取到 assets/images/（EMF 等不可渲染格式自动转 PNG）；输出默认「源文档同目录/{文档名}-spec/」子目录，输出与图片目录均可配置。说「整理成需求规格」时另出需求点+验收标准与功能单元切片（可选档）。

## 使用方式

1. 直接说「把这份 Word 转成 Markdown」「这份 PDF 转成文档」并给出文件路径
2. 未装 Pandoc 时按引导安装（macOS brew / Windows winget / Linux apt-get）
3. Pandoc 完成机械转换后，AI 对照原文逐段校对（量化断言/完整性/表格/图片/乱码/修订痕），整理出 01-正文.md
4. 需要需求规格时说「顺便整理成需求规格」——AI 另出需求点+验收标准与功能单元切片

## 支持格式

- .docx（Pandoc 转换，图片自动提取）
- .md（直接读取）
- .pdf（LibreOffice 转 docx 优先，保留图片版式；无 LibreOffice 降级纯文本提取）

## 常用说法

- 「输出到桌面」→ 临时改输出目录（仍按文档名建子目录）
- 「直接放这个目录」→ 产物平铺到指定目录不建子目录
- 「图片放 figures/」→ 临时改图片目录
- 「整理成需求规格」→ 启用需求加工档
- 「先看看效果」→ 先出预览确认再落盘

## 产出

{文档名}-spec/ 目录：README 索引 + 01-正文.md（校对整理稿）+ 图片目录 + 澄清清单（有疑点时）；需求加工档启用时另含 01-需求规格.md 与 requirements/ 切片。

## 触发词
