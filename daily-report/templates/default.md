# 模板：default（内置默认 · 三段式）

> 本文件随 skill 升级更新，勿直接改；自定义模板请放同级 `user-templates/`。

## 骨架

# 今日日报 - YYYYMMDD

> 生成时间：YYYY-MM-DD HH:MM:SS

## 今日任务进度
1、任务描述（量化数据：文件数/行数/提交次数）- 进度XX% - 用时XH

## 明日计划
1、任务描述 - 完成标准：XX（时间点）- 进度XX% - 预估用时XH

## 风险阻塞点
- 问题描述；影响：xxx；建议：xxx；责任与时间：xxx（谁/何时，口述有时必写）

## 段要点

- 今日任务进度 3-6 点、每点 20-40 字；序号用中文顿号（1、2、3）
- 三段兜底写「暂无」；计划点带进度百分比与预估用时，口述给出完成标准时必写「完成标准：XX（时间点）」
- 风险阻塞点四环（问题+影响+建议+责任与时间），第四环口述有时必写；不写进度用时
- 用时单位 XH（小时），估算值注明「约」
