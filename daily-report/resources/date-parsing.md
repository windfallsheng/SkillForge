# 日期解析（自然语言优先）

先解析用户话术得到目标日期 YYYY-MM-DD，再收集该日提交。解析规则：

| 说法示例 | 解析规则 |
|---|---|
| 写日报 / 生成日报（未提任何日期） | **默认今天，不追问** |
| 今天的日报 / 今日日报 / 当天的日报 | 今天 |
| 昨天的日报 / 昨日日报 | 今天 -1 天 |
| 前天的日报 / 大前天的日报 | 今天 -2 / -3 天 |
| N 天前的日报 | 今天 -N 天 |
| 上周X的日报（如上周三） | 上一周的周 X（周一为一周起点） |
| 10月20号的日报 / 10月20日 | 缺年份默认当前年；若该日期晚于今天，取去年同日 |
| 20261020 / 2026-10-20 | 直接使用 |
| 10月20号到10月25号的日报 / 11.05~11.07 / 上周一到上周五 / 10月20号到今天 | 连续日期批量生成：两端分别按本表单点规则解析（终点缺年份沿用起点年份、终点月份早于起点月份视为下一年，如「12月28号到1月3号」；终点可写「今天/昨天」），按日期正序逐日生成一份日报 |

- 目标日期写入日报标题与 git log 的 --since/--until
- 批量生成流程：先一次性收集区间内所有日期的提交（逐日分片 --since/--until），再按日期正序逐日生成（每日可引用后一天数据做「明日计划」，见「输出内容与数据来源」节），最后统一落盘与截图；批量时只自动打开最后一天（最新一天）的 html、其余仅落盘不开浏览器，避免开多个标签页；对话中按日期分隔输出各天 md 正文
- 落盘子目录名永远用解析出的目标日期（"昨天的日报"→ 昨天日期），与生成当天/生成时刻无关，不因跨零点而改变
- 未提及任何日期词（如"今天/昨天/10月20号"）时，一律默认今天直接生成，不追问用户
- 解析结果有歧义时以最近过去的日期为默认，并在标题中注明解析出的日期
