# 本地落盘（默认行为）

- 落盘根目录读取顶部「默认配置」的 `DIR`（默认 `auto`：按当前系统自动选 `DIR_MAC` / `DIR_WIN`），按目标日期分子目录（macOS：`<DIR>/YYYY-MM-DD/`；Windows：`<DIR>\YYYY-MM-DD\`，目录不存在则自动创建）；改配置节里的 DIR / DIR_MAC / DIR_WIN 即可改变默认位置
- 换机器/目录不存在回退：落盘前检测 DIR 是否存在（macOS：`test -d <DIR>`；Windows：PowerShell `Test-Path '<DIR>'` 或 node `fs.existsSync`），目录/盘符不存在时默认根目录自动改用用户主目录下 reports（macOS=`~/reports`、Windows=`%USERPROFILE%\reports`，不存在则自动创建），保证任何机器都能落盘
- 使用时用户临时指明位置（如"写到桌面"、"存到 ~/report（macOS）/ D:\report（Windows）"，覆盖 DIR、仅当次生效）：以用户指定位置为根目录，同样按日期分子目录；"桌面"映射：macOS=`~/Desktop`、Windows=`%USERPROFILE%\Desktop`；目录不存在自动创建
