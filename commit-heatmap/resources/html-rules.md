# 热力图 HTML 版式（GitHub 风格三主题）

## 版式总览

- GitHub 风格热力图：53 周列 × 7 天行格子矩阵（周起周日），格子 11px 圆角 2px、间距 3px；颜色按提交数五档深浅（0 档底色 var(--cell-0) 极浅，1 档 / 2 档 / 3 档 / 4+ 档逐级加深，档位变量 --cell-1 ~ --cell-4）；格子 hover 放大 + tooltip「MM-DD · N 次提交」
- 三主题：github 经典绿（默认，浅底 #ffffff 系 + 绿色格）/ dark 深夜绿（深底 #0d1117 + 亮绿格）/ amber 琥珀金（暖底 + 金橙格）；`html[data-theme]` 运行时切换；右下角换肤坞三点随点随换、localStorage 记忆（键 `heat:<ID>-theme`，ID = 页内嵌 heat-id meta，多份产物互不串台、改名/移动目录记忆不丢）
- 字体全用系统本地字体栈（system-ui + ui-monospace/'SF Mono'/Menlo/Consolas，品牌字体 PingFang/YaHei/apple-system 零出现），禁止 CDN、@import、外链 CSS/JS/图片/网络字体——页面离线双击可开
- 多文件隔离（必植）：头部写 `<meta name="heat-id" content="<UUID>">`（crypto.randomUUID() 标准 UUID v4）；localStorage 键一律 `heat:<ID>-xxx`，禁止裸通用键名；页面 JS 启动时校验 id meta——非法或缺失（占位残留/手写变体/误沿用旧值）时按路径键（`'sf-heal:' + location.pathname`）自愈为 crypto.randomUUID() 标准 v4 并回写 meta，console.warn 显性报警；路径键持久化保证同文件跨打开稳定复用；合法 UUID 原样放行
- 版本戳：`<meta name="sf-template" content="commit-heatmap@1">`（模板升级递增 @N）
- 布局：头部标题卡（标题 + 日期区间徽章）+ 统计卡四张横排（总提交数/最长连续天数/活跃日占比/最活跃日）+ 热力图容器（左侧月份纵标 + 顶部星期横标 + 格子矩阵）+ 图例（少 → 多 五色块）；宽度超出容器横向滚动（.grid-scroll overflow-x:auto）
- 入场动画：标题卡与统计卡错峰上浮淡入；fill-mode 必须用 backwards 严禁 both；滚动入场用 IntersectionObserver + 2s 兜底 setTimeout 强制全显（headless 截图 / 打印预览环境格子不得永久隐藏）
- 页脚 10px muted 文字，署名固定 GENERATED BY AI TEAM（禁止真实团队名/项目名）

## 渲染规则

- `window.HEAT_DATA`：日期 → 次数映射；渲染从统计区间起点所在周的周日对齐补全至今天所在周，缺失日期补 0 档
- `window.HEAT_STATS`：{total, streak, active, topDay, topCount} 五项统计（active 为百分比数字）
- 格子 title 属性即 tooltip 兜底（原生 title，不引第三方库）；今天所在格子加描边高亮
- ?shot 截图模式：页面 JS 检测 location.search 含 shot 时给 html 挂 data-shot 属性（CSS 关闭入场动画直接终态，headless 虚拟时间下动画帧不推进会停在初始帧导致截图空白）、强制全部卡片 opacity 1、隐藏标题卡/换肤坞/图例外的装饰，body 四周 padding 统一 40px
