# 提交热力图使用指南

## 能做什么

把 git 仓库近一年提交变成一张 GitHub 风格的提交热力图 HTML：53 周×7 天格子、颜色按提交数五档深浅、悬停显示日期与次数、四张统计卡（总提交数 / 最长连续提交天数 / 活跃日占比 / 最活跃日），离线零依赖双击可开，三主题可切换。

## 怎么用

1. 说「**生成提交热力图**」或「**看看我的代码活跃度**」→ 默认当前仓库近一年
2. 可顺口指定：「只看最近 90 天」「统计 XX 仓库」「按作者分开出图」
3. 产出：`reports/commit-heatmap.html`，自动打开浏览器，落盘后报路径与四项统计

## 可改配置（user-config.md）

- `REPO`：仓库根目录（默认当前目录向上探测）
- `DAYS`：统计天数（默认 365）
- `THEME`：github 经典绿 / dark 深夜绿 / amber 琥珀金
- `EXCLUDE`：排除名单（bot 邮箱 / vendor 路径等）

## 使用提示

- 合并提交默认不计数，需要包含时说一声
- 页面纯本地渲染，无网络请求，数据不离开你的机器
