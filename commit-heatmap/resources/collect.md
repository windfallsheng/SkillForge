# 收集数据（阶段 1）

> ⚠️ 本文件是收集机制说明，不是配置区——随 skill 升级会被官方版覆盖。git 仓库等配置（REPO/DAYS/EXCLUDE 等）只写在同目录外的 `user-config.md`（升级保护区，永不覆盖）。


## 聚合命令

```bash
git -C <REPO> log --since="<DAYS> days ago" --until="today 23:59:59" --no-merges   --pretty=format:'%ad|%ae' --date=format:'%Y-%m-%d'
```

- 按行解析「日期|邮箱」，按日累加计数 → `{"YYYY-MM-DD": N}` 映射
- EXCLUDE 非空时：对每条提交用 `git log --pretty=format:'%ae|%an' -- <path>` 核对或直接按邮箱/路径关键词过滤，排除的提交计数减去
- 多作者仓库可按 `%ae` 分作者出多份（用户指定「按作者分」时）

## 统计派生

1. **总提交数**：所有日期计数之和
2. **最长连续提交天数**：日期集合按天扫描连续段，取最长段天数（当前未断的连续段标注「进行中」）
3. **活跃日占比**：有提交的天数 / DAYS
4. **最活跃日**：计数最高的日期 Top 1（并列取最近）

## 输出

`{"2026-11-12": 3, ...}` 映射 + 四项统计数字，交给阶段 2。日期零计数的日子自然缺失，渲染层补零。
