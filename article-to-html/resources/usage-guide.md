# 文章装裱师使用指南

当用户问「这个技能怎么用」「使用说明」「能干什么」时，用本节的人话版说明回复，不要复述内部流程术语（骨架侦察/零侵权核查等）。

### 能干什么（三句话版）

1. **文档变网页**：把 Word / Markdown / 纯文本文章装裱成带封面的精美 HTML 页面——免费商用字体、图表矢量重绘、双击即开
2. **已有页面美化**：给一个现成的 HTML 换装修（配色/排版/组件样式），不动正文文字
3. **按章节截图**：把文章页面按章节截成统一宽度的高清图（1460px），适合公众号配图与拼长图

### 用户怎么开口（示例话术）

| 用户说（说法可以换） | 技能做 |
|:---|:---|
| 「把这篇文章转成 HTML」「做成网页」「排版一下」「公众号排版」 | 走全流程：解析 → 建页面 → 截图前先问一句效果满意否 |
| 直接丢一个 .docx / .md / .txt 文件路径（什么都不说也行） | 同上，丢路径即触发 |
| 「把这篇 Word 转成好看的网页，顺便截个图」 | 全流程，用户点头后自动逐章截图 |
| 「这个页面美化一下」「装修一下」「换个配色」「好看点」 | 只装修已有 HTML，不改正文 |
| 「这个 HTML 按章节截图」「截成长图」「每章一张图」「出图」 | 只截图，先看页面结构再逐章定格 |
| 「使用说明」「怎么用」「能干什么」「有什么功能」 | 回复本节的人话版用法说明 |

### 过程中会问什么

- **字体**：系统缺思源黑体时，问是否自动安装（全页只许 Roboto + 思源黑体，无替代字体）
- **风格**：文章气质拿不准时，让用户在 2-4 款版式候选里挑
- **确认一**：页面做好后、截图前问「效果满意吗」——可反复调，至多 3 轮
- **确认二**：截完图请用户抽看封面 + 最长章节两张图，发现缺字/截断只重截该章

### 交付物

- `<标题>.html`——标准版（配 assets/fonts 字体文件）
- `<标题>-单文件版.html`——字体全内嵌，双击即开、可随意移动分享
- `文章截图/章节截图/C00-封面.png … C0N-xx.png`——统一 1460px 宽，按序拼接即整篇长图

### 常见问题

- **为什么截图统一 1460px 宽？** 统一规格便于拼长图、发公众号，Retina 2x 保证高清
- **为什么只有 Roboto + 思源黑体？** 两者均为免费商用授权，其余字体一律不用，零侵权
- **单文件版什么时候给？** 定稿后重铸一次；中途调整期间不重铸以省时间
- **改过的文章再处理？** 会先问「覆盖重生成 / 只重新截图 / 仅改样式」三选一
- **页面能换主题色吗？** A 款页面右下角四个色点随时切换（科技蓝/暖棕金/墨绿/梅紫），浏览器记住上次选择；默认主题色在 user-config.md 的 THEME 配置里改

### 效果不对怎么办

- 页面 / 截图效果不对（第 X 章有 XX 问题、布局乱、字体显示异常），对 AI 说「第 X 章截图有 XX 问题，对照设计标准修复」，把问题描述清楚（哪一章、什么现象，能截图最好）
- 本技能的设计标准：`resources/reference.html` 是 A 款页面真相源（骨架 + 全部组件示范），`design-system.md` 提供六款版式参数；AI 修复时先 Read reference.html 为标准
- AI 的处理流程固定：先 Read reference.html 与 design-system.md 作标准 → 再读那份问题 html 逐处比对 → 以设计真相源为准修复 → 重跑字体合规核查（任何未授权字体必须清零）→ 重截问题章节截图自证
- 字体显示成方框/豆腐块：优先说「缺字」，AI 会先检查系统是否装了思源黑体（本技能字体白名单锁死 Roboto + 思源黑体，无兜底）
