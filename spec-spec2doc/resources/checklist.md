# AI 回验清单（转换后必做）

机械产物不直接交付。AI 转换后必须回验，发现问题修正源稿重新转换，直到通过。

## 回验方法

- Word 内容比对：`pandoc <输出.docx> -t gfm` 反向转回 md，与源 md 逐段比对（章节/段落/表格/列表是否完整无遗漏）
- 图片嵌入核对：`unzip -l <输出.docx> | grep media` 确认图片全部嵌入；数量与源 md 引用数一致
- 文件可开性：docx 大小异常（接近 0KB 或数倍膨胀）→ 转换失败信号，重转排查
- PDF 回验：`pdftotext <输出.pdf> - | wc -l` 文本行数合理（非 0 非异常少）；必要时截图查看版式

## 检查项

- 内容完整：无章节/段落/表格遗漏（反向转换比对）
- 标题层级：各级标题样式正确，目录（TOC）条目与正文一致
- 表格：不超宽溢出、无拆裂（超宽表 AI 提前拆分为多表或改列表呈现）
- 图片：全部嵌入且显示正常（EMF/WMF 源图同样先转 PNG 再转 Word，转换链同 doc2spec 的 images.md：soffice headless → qlmanage → magick）
- 中文显示：PDF 中文不豆腐块（LaTeX 路径需 CJK 字体，见 pdf-path.md）
- 乱码/格式错乱：特殊字符、公式、代码块变形 → 修正源稿重转

## 重转纪律

- 每轮回验记录问题清单；修正源稿 → 重新转换 → 再次回验
- 重转不超过 3 轮；仍不通过时如实报告用户「哪些项无法修复 + 原因」，不交付带错文档
