# 用户配置（升级技能时本文件不会被覆盖）

> 你的个人配置全放在这里。skill-forge 升级技能时官方只更新 SKILL.md 与 resources/，
> 本文件始终保留你的版本——落盘目录、格式开关放心改。
> 官方升级若带来新配置点，会另存 `user-config.upstream.md` 对照文件到同目录，
> 你按需查看并手动合并新配置点到本文件。

## ⚙️ 默认配置（用户可手动修改；临时口头要求永远优先）

```yaml
CONFIG_VERSION: 1              # 配置结构版本：skill 升级时若配置结构变化会递增；AI 每次执行前对比 SKILL.md「配置版本机制」节声明的当前版本，不一致时按迁移规则处理（先备份本文件为带时间戳 .bak，再迁移，最后对话告知用户）
DISK: true                     # 示例配置项：是否落盘写文件；false = 默认只在对话输出
DIR: auto                      # 示例配置项：落盘根目录
TEMPLATE: default              # 示例配置项：模板开关（default 默认模板 / custom 自定义模板）
```

> 临时口头要求（仅对当次生效，不修改上方配置）：说「xxx」→ 当次改某行为；……

## 📝 自定义模板（TEMPLATE: custom 时启用，用户可手改）

把 TEMPLATE 改为 custom 后，按下面结构生成（段名、段数、条目格式均可改）：

```text
段一：……（每条：……）
段二：……（每条：……）
```

> 只写段结构与条目格式即可；未写明的细节沿用默认规范。
