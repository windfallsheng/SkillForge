# 魔法幻灯生成（magic-deck）

把用户内容排版为单文件 HTML 幻灯片（16:9 舞台 + 播放引擎 + 四套风格 + 全屏放映），落盘并自动打开。

## 生成流程

0. **读用户配置**（TEMPLATE/THEME/WIDTH/HEIGHT/SEC/FILENAME/DIR 等）→ 先 Read 同目录 `user-config.md`
1. **收集内容**：解析用户提供的内容（文字/文件/结构化要点），确定页数与每页版式
2. **生成 HTML**（每页写语义结构——.s-head 标题 / .card 卡片 / .points 要点 / .bignum 数据，按 TEMPLATE 在对应页 slide 挂 data-template 声明默认版式；四主题 CSS 变量、单页主题按钮、模板面板、播放引擎、热键、截图/复制、全屏纯净模式）→ 先 Read `resources/reference.html` + `resources/deck-spec.md` 两份，以 reference.html 为骨架逐处替换内容
3. **落盘与命名**：写 `<文件名>.html` 到 DIR 目录，自动打开浏览器供用户放映。命名三级优先：①用户口头指定文件名 → 用指定名；②未指定且 FILENAME=auto → 按本次内容主题+用途总结中文名（如「智能探针系统-产品介绍」，让用户日后能按名找回继续改）；③FILENAME 写死固定名 → 用固定名。重名一律自动加日期后缀，绝不覆盖；落盘目录复用不清空、不改动目录内既有文件
4. **使用咨询**（用户只问「怎么用」等用法、未要求生成）→ 输出纯文字使用指南（功能/热键/截图/复制/全屏/主题），不生成 HTML

## ⚙️ 配置与自定义

**执行本 skill 前必须先 Read 同目录 `user-config.md`**：默认配置（TEMPLATE/THEME/WIDTH/HEIGHT/SEC/FILENAME/DIR 等）与用户模板都在该文件中，以它为准。升级技能时 user-config.md 不会被覆盖，你的修改永久保留；官方更新配置时另存 `user-config.md.upstream` 对照文件，可按需手动合并新配置点。

## 规则速览

- 单文件 HTML 离线双击可打开：禁用 CDN/@import/外链 CSS/JS/图片/网络字体，字体用系统栈
- 模板五套（版式骨架）与主题四套（配色）正交组合，均运行时即点即换：模板经「🎨 模板」面板应用（全部页/仅本页/勾选页），生成时按 TEMPLATE/口头点名在 slide 挂 data-template 声明默认版式；标题自动映射——timeline 取卡片标题做节点、keynote 取页标题做大观点、magazine 左文右图分栏，切回经典商务恢复原排版内容不丢；`.slide` 自带 `background:var(--bg)` 使单页换肤整页变色
- 工具栏控件统一 flex 垂直居中：`.toolbar/.group` flex + align-items:center + gap；`.tbtn` inline-flex + gap:6px + line-height:1；checkbox 14×14 与文字 6px 间距，文字不贴控件、上下不偏斜
- 页面 1280×720 舞台 + 按窗口等比缩放（--sc），窗口任意大小不变形
- 结构顺序：背景装饰 → 顶部进度条 → 工具栏 → 页码 → 提示 → 左右箭头 → 舞台页组 → 说明弹层 → 播放引擎
- 左右箭头不常驻：默认透明，鼠标在页面内才显现；触屏设备（hover:none）保持可见
- 全屏放映纯净模式：`:root:fullscreen` 下工具栏/页码/提示/箭头/弹层与背景氛围层全部隐藏、页面黑底 `#000`（与 PPT 软件放映一致：幻灯按比例充满画面，比例不匹配处补黑边，绝无主题氛围边框），只留主体；热键全屏下照常生效
- 截图与复制只含主体内容，绝不包含工具栏/页码/箭头等操作元素；复制分「⧉ 复制本页」（当前页文字）与「▦ 选页复制」（面板勾选任意页、默认全选=一键复制全部，按「【第 N 页】」分隔）；截图分「📷 截图本页」与「▦ 选页截图」（面板勾选任意页、默认全选=串行逐张下载全部页 slide-页码-主题.png，进度实时显示已保存 k/N 页；文字通道不含图片，图片走截图）
- 落盘命名三级优先：口头指定 > FILENAME=auto 按主题+用途总结中文名 > 写死固定名；重名加日期后缀不覆盖，目录复用不清空
- 完整规范（骨架/主题色值/模板库/单页主题/播放引擎/热键表/截图实现）见 `resources/deck-spec.md`

## 🔧 配置版本机制（升级保护）

`user-config.md` 首行有 `CONFIG_VERSION` 字段，声明配置结构版本。本 skill 当前要求版本为 1。每次执行前先读 user-config.md：

1. 若 CONFIG_VERSION 缺失或小于当前要求版本：先将旧 `user-config.md` 备份为 `user-config.md.bak-<时间戳>`
2. 按版本迁移规则迁移字段（新增字段补默认值、改名字段按映射改名、删除字段保留在备份并在对话中提示用户）
3. 更新 `CONFIG_VERSION` 为当前版本
4. 对话告知用户「配置已升级到 vN：新增 X、改名 Y」

禁止在未声明版本变更的情况下静默修改配置语义；升级技能时 user-config.md 不会被覆盖（官方更新另存 `user-config.md.upstream` 对照文件）。
