# 魔法幻灯生成器使用说明

> 本文件是使用咨询的应答源：用户只问「怎么用 / 使用说明 / 能干什么」时，将本文件内容原样输出（首行标题改为「魔法幻灯生成器使用指南」），不执行任何生成动作。

## 能干什么（三句话版）

1. **内容变幻灯**：把一段文字、一份大纲或一个文件，做成单文件 HTML 幻灯片——16:9 舞台、双击即开、离线可用
2. **现场改版**：版式模板十六套（经典商务 / 极简留白 / 杂志画册 / 黑金发布……）与主题配色十七套即点即换，可套全部页或仅当前页；「💼 领域」Tab 还有二十一套成套模板（毕业答辩 / 年终汇报 / 商业计划书 / 政务汇报……），一键生成整套页面
3. **放映与出料**：自动播放 / 全屏纯净放映 / 翻页动画与元素动画库；逐页 PNG 截图与本页 / 选页文字复制（均不含工具栏等操作元素）

## 工具栏与边栏

- **🎨 模板**：十六套版式骨架，应用范围可选全部页面 / 仅本页 / 勾选页面；先「预览本页」看效果再应用，切回「经典商务」恢复原排版、内容不丢
- **🎨 主题**：十七套配色，色点即点即换，范围可选全部页面或仅本页
- **↶ ↷ 撤销 / 重做**：模板应用、增删页、换主题等所有编辑操作都可回退
- **▤ 页导航**：右侧缩略图边栏——点缩略图跳页、＋新页（16 版式任选）、复页、排序、删页
- **⚙ 工具**：右侧边栏第二页签——翻页动画八套、元素入场 / 离场 / 强调动画、标题文字动画、⧉ 复制本页 / ▦ 选页复制 / 📷 截图本页 / ▦ 选页截图
- **▶ 自动播放**：间隔 3s / 5s / 8s / 10s 可设，可循环、可从当前页或从头开始

## 常见问题

- **截图存到哪？** 截图 / 选页截图通过浏览器下载通道保存（逐张 PNG，命名含页码与主题名）；选页截图面板默认全选 = 一键导出全部页
- **复制只想要文字？** 复制通道只取页面文字（多页按「【第 N 页】」分隔）；图片内容请走截图
- **改完怎么保存？** 页面的编辑与换肤作用于当前打开的内存副本，刷新后回到原始文件；要固化效果请把新的版式 / 主题告诉 AI，让它重新生成 HTML
- **放映时怎么干净？** 按 F 进全屏：工具栏、页码、箭头、弹层全部隐藏，画面纯黑背景只留幻灯内容，与 PPT 软件放映一致
- **能拿到 PPT 吗？** magic-deck 产出 HTML 幻灯；要 .pptx 文件请用「登台 deck-stage」技能（报告 / 素材转专业 PPT，原生可编辑）
