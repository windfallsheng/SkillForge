# 内容适配手册（生成前选版式）

> 生成 HTML 前必读：按内容气质挑版式骨架、按领域挑成套模板、按用途定页数节奏、按数据挑图表形式。拿不准时用 AskUserQuestion 让用户在候选里挑，不替用户做风格决策。

## 一、内容气质 → 版式骨架（十七套怎么挑）

| 内容类型 | 首选版式 | 备选 | 理由 |
|:---|:---|:---|:---|
| 产品发布 / 路演 | keynote 黑金发布 | classic 经典商务 | 大观点单页冲击力强，黑金适合发布场 |
| 数据汇报 / 财报 | finance 金融报表 | bento 模块网格 | 仪表环 + 数据卡原生就位 |
| 高管简报 | executive 高管简报 | minimal 极简留白 | 一页一结论，克制利落 |
| 教学培训 | education 教学板书 | steps 流程步骤 | 板书分栏 + 目标/讲解/练习三段 |
| 技术分享 / 架构 | blueprint 蓝图工程 | metro 扁平磁贴 | 工程感线条与图纸气质 |
| 时间线叙事 / 复盘 | timeline 时间线叙事 | vintage 复古报纸 | 节点卡片天然承载阶段演进 |
| 文艺 / 故事 / 品牌 | magazine 杂志画册 | poster 海报宣传 | 左文右图分栏 + 大幅留白 |
| 新闻通讯 / 资讯 | vintage 复古报纸 | classic 经典商务 | 双栏报纸排版信息密度高 |
| 活动海报 / 单页宣传 | poster 海报宣传 | magazine 杂志画册 | 要点转斜切色带，视觉先行 |
| 极简个人页 / 简历 | minimal 极简留白 | bento 模块网格 | 居中大字 + 要点列表 |

| 统计看板 / 数据大屏 | stats 统计图表 | finance 金融报表 | KPI 大数字横排 + 图表框架，看板气质 |

## 二、领域成套模板（二十二套，六分类怎么挑）

用户内容主题与某套高度契合时，优先推荐领域模板（一键生成整套：封面 + 目录 + 内容页 + 图表页 + 结束页，每套 6-8 页）：

| 分类 | 模板 | 适用场景 |
|:---|:---|:---|
| 教育学术 | thesis 毕业答辩 / proposal 开题报告 / teaching 教学课件 | 学位答辩、课题申报、课堂 |
| 职场商务 | report 年终汇报 / competition 竞聘述职 / plan 商业计划书 / hiring 求职简历 | 述职、融资、求职 |
| 企业运营 | product 产品发布 / tech 科技发布会 / marketing 营销方案 / sales 销售方案 / training 企业培训 / ceremony 年会盛典 | 发布会、销售提案、培训、年会 |
| 专业领域 | finance 金融分析 / medical 医疗科普 / law 法律合规 | 行业分析、科普、合规宣贯 |
| 党政政务 | gov 政务汇报 / party 党建汇报 | 政府汇报、党建活动 |
| 生活场景 | food 餐饮品牌 / travel 旅游攻略 / festival 节日庆典 / charity 公益慈善 | 探店、攻略、节庆、公益 |

生成后领域模板与版式 / 主题正交：每页仍可挂 data-template 运行时换十七版式、主题照常换肤，不是死骨架。

## 三、页数与节奏

| 用途 | 建议页数 | 结构 |
|:---|:---|:---|
| 工作汇报 / 述职 | 6-8 页 | 封面 1 + 目录 1 + 正文 3-4 + 图表 1 + 结束 1 |
| 教学培训 | 8-10 页 | 封面 + 目标 + 讲解 4-6 + 练习 + 小结 |
| 路演 / 发布会 | 8-12 页 | 封面 + 痛点 + 方案 3-5 + 数据 + 里程碑 + 结束 |
| 单页海报 | 1 页 | 大字标题 + 3-5 条要点 + 落款 |

**页内纪律**：单页要点 ≤ 5 条；单页数据指标 ≤ 3 个；页标题 ≤ 12 字；超量自动拆页，禁止一页塞满。

## 四、图表选型（挂 data-anim-chart）

| 数据形态 | 图表 | 容器挂法 |
|:---|:---|:---|
| 趋势 / 变化 | line 折线描画 | `data-anim-chart="line"` |
| 占比 / 构成 | pie 饼图扇入 | `data-anim-chart="pie"` |
| 对比 / 排名 | bars 柱状生长 | `data-anim-chart="bars"` |
| 完成率 / 进度 | ring 仪表扫弧 | `data-anim-chart="ring"` |
| 大数字 / 里程碑 | count 数字滚动 | `data-count="128"`（可带 `data-count-dec`） |

数值纪律：业务结果指标优先、git 统计兜底；数字必带对比基准（同比 / 环比）。
