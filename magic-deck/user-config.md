# 用户配置（升级技能时本文件不会被覆盖）

> 你的个人配置全放在这里。skill-forge 升级技能时官方只更新 SKILL.md 与 resources/，
> 本文件始终保留你的版本——默认主题、页面尺寸、默认播放间隔、文件名、落盘目录放心改。
> 官方升级若带来新配置点，会另存 `user-config.md.upstream` 对照文件到同目录，
> 你按需查看并手动合并新配置点到本文件。


## ⚙️ 默认配置（用户可手动修改；临时口头要求永远优先）

```yaml
CONFIG_VERSION: 1              # 配置结构版本：skill 升级时若配置结构变化会递增；AI 每次执行前对比 SKILL.md「配置版本机制」节声明的当前版本，不一致时按 SKILL.md 的迁移规则处理（先备份本文件为带时间戳 .bak，再迁移，最后对话告知用户）

# ── 落盘与外观 ──
DIR: ~/Desktop            # 幻灯片 HTML 落盘目录
FILENAME: auto            # 文件名（不含扩展名）：auto = 按本次内容主题+用途自动总结中文名（如「智能探针系统-产品介绍」，便于日后按名找回继续改）；也可口头指定文件名（永远优先）；或写死固定名如 slides（重名自动加日期后缀，不覆盖）
OPEN_HTML: true           # 生成后自动打开浏览器放映
THEME: tech               # 默认主题：tech 深蓝科技 / biz 浅色商务 / mono 极简黑白 / warm 温暖渐变（放映时工具栏可整份切换或「仅本页」单页换肤）
TEMPLATE: classic         # 默认模板（版式骨架，与主题正交可自由组合）：classic 经典商务 / minimal 极简留白 / magazine 杂志画册 / keynote 黑金发布 / timeline 时间线叙事
WIDTH: 1280               # 舞台宽度（16:9 基准，改宽高请同步改 deck-spec 同值）
HEIGHT: 720               # 舞台高度
SEC: 5                    # 自动播放默认间隔（秒，可选 3/5/8/10）

# ── 播放行为 ──
LOOP_DEFAULT: false       # 循环播放默认关（放映时可勾选）
FROM_START_DEFAULT: true  # 从头播放默认开（取消勾选=从当前页继续）

# ── 页脚署名 ──
SIGNATURE: GENERATED BY SKILLFORGE   # 封面/结束页署名
```


## 📝 模板与主题（像真 PPT 一样可选）

- **内置模板五套**（版式骨架，生成时生效）：classic 经典商务（默认）/ minimal 极简留白 / magazine 杂志画册 / keynote 黑金发布 / timeline 时间线叙事。改上方 `TEMPLATE` 即换默认，或生成时口头点名（如「用杂志风模板」）当次生效
- **内置主题四套**（配色，放映时随时换）：tech / biz / mono / warm。工具栏色点点击=整份切换；点「⭮ 仅本页」后再点色点=只给当前页换肤，再点一次恢复整份模式
- **自定义模板片段**（可选）：在 `resources/templates/` 下放 `my-*.html`（仅 body 内容片段，不含 html/head/script），生成时用户点名模板名即可套用；未点名用内置五套模板
