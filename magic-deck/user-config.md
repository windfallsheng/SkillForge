# 用户配置（升级技能时本文件不会被覆盖）

> 你的个人配置全放在这里。skill-forge 升级技能时官方只更新 SKILL.md 与 resources/，
> 本文件始终保留你的版本——默认主题、页面尺寸、默认播放间隔、文件名、落盘目录放心改。
> 官方升级若带来新配置点，会另存 `user-config.md.upstream` 对照文件到同目录，
> 你按需查看并手动合并新配置点到本文件。


## ⚙️ 默认配置（用户可手动修改；临时口头要求永远优先）

```yaml
CONFIG_VERSION: 2              # 配置结构版本：skill 升级时若配置结构变化会递增；AI 每次执行前对比 SKILL.md「配置版本机制」节声明的当前版本，不一致时按 SKILL.md 的迁移规则处理（先备份本文件为带时间戳 .bak，再迁移，最后对话告知用户）

# ── 落盘与外观 ──
DIR: ~/Desktop            # 幻灯片 HTML 落盘目录
FILENAME: auto            # 文件名（不含扩展名）：auto = 按本次内容主题+用途自动总结中文名（如「智能探针系统-产品介绍」，便于日后按名找回继续改）；也可口头指定文件名（永远优先）；或写死固定名如 slides（重名自动加日期后缀，不覆盖）
OPEN_HTML: true           # 生成后自动打开浏览器放映
THEME: tech               # 默认主题（十六套：tech 深蓝科技 / biz 浅色商务 / mono 极简黑白 / warm 温暖渐变 / aurora 极光紫 / dracula 德古拉紫 / nord 北欧冰蓝 / midnight 东京夜色 / matrix 终端荧光绿 / cyber 赛博霓虹 / apple 苹果极简 / stripe 条纹紫蓝 / notion 纸感暖白 / gruvbox 复古暖橙 / gold 黑金奢华 / ocean 深洋蓝；放映时「🎨 主题」面板色点即点即换：范围可选全部页面或仅本页）
TEMPLATE: classic         # 默认模板
TRANSITION: slide-lr     # 默认翻页动画风格（八套：slide-lr 左右滑移 / fade 淡入淡出 / slide-ud 上下滑移 / zoom 缩放推进 / flip 3D 翻页 / cube 立方翻转 / wipe 平移擦除 / dissolve 溶解模糊；放映时边栏「⚙ 工具」Tab 即点即换，选择记忆）
ANIM: true               # 元素动画默认开（入场十二式挂 data-anim + 离场十二式挂 data-anim-leave + 强调八式挂 data-anim-emphasis + 标题文字动画，均带 data-anim-delay 八档错落；放映时边栏「⚙ 工具」Tab「开启」勾选框一键全关；false = 生成时 deck 挂 data-anim="off"）
WIDTH: 1280               # 舞台宽度（16:9 基准，改宽高请同步改 deck-spec 同值）
HEIGHT: 720               # 舞台高度
SEC: 5                    # 自动播放默认间隔（秒，可选 3/5/8/10）

# ── 播放行为 ──
LOOP_DEFAULT: false       # 循环播放默认关（放映时可勾选）
FROM_START_DEFAULT: true  # 从头播放默认开（取消勾选=从当前页继续）

# ── 页脚署名 ──
SIGNATURE: GENERATED BY SKILLFORGE   # 封面/结束页署名
```


## 📝 模板、主题与动画（像真 PPT 一样可选）

- **内置模板十六套**（版式骨架）：classic 经典商务（默认）/ minimal 极简留白 / magazine 杂志画册 / keynote 黑金发布 / timeline 时间线叙事 / steps 流程步骤 / poster 海报宣传 / vintage 复古报纸 / finance 金融报表 / blueprint 蓝图工程 / education 教学板书 / executive 高管简报 / metro 扁平磁贴 / bento 模块网格 / dark 暗夜深色 / nature 自然清新。改上方 `TEMPLATE` 即换生成默认，或生成时口头点名（如「用杂志风模板」）当次生效；放映时随时经工具栏「🎨 模板」面板切换（全部页面/仅本页/选择页面），可先「预览本页」看效果再应用，标题自动映射到模板固定位置，切回经典商务即恢复原排版
- **内置主题十六套**（配色，放映时随时换）：tech 深蓝科技（默认）/ biz 浅色商务 / mono 极简黑白 / warm 温暖渐变 / aurora 极光紫 / dracula 德古拉紫 / nord 北欧冰蓝 / midnight 东京夜色 / matrix 终端荧光绿 / cyber 赛博霓虹 / apple 苹果极简 / stripe 条纹紫蓝 / notion 纸感暖白 / gruvbox 复古暖橙 / gold 黑金奢华 / ocean 深洋蓝。「🎨 主题」面板点色点=整份切换；范围选「仅本页」后再点色点=只给当前页换肤，选回「全部页面」即恢复整份模式
- **动画库**（动效，与模板/主题正交，放映时收纳在右侧边栏「⚙ 工具」Tab，应用范围可选全部页面/仅本页）：翻页风格八套——slide-lr 左右滑移（默认）/ fade 淡入淡出 / slide-ud 上下滑移 / zoom 缩放推进 / flip 3D 翻页 / cube 立方翻转 / wipe 平移擦除 / dissolve 溶解模糊，改上方 `TRANSITION` 即换生成默认，放映时即点即换；元素入场动画十二式（fade-up 上浮 / fade-in 淡入 / fade-down 下沉 / zoom-in 缩放 / slide-left 左滑 / slide-right 右滑 / slide-up 上滑 / slide-down 下滑 / pop 弹出 / bounce-in 弹跳 / flip-in 翻转 / blur 模糊浮现，另有 none 无动画），生成时元素挂 `data-anim` 属性声明、同页多元素挂 `data-anim-delay` 错落，翻到该页自动播放；离场动画十二式（元素挂 `data-anim-leave`，翻页前元素先离场 0.45s 再切页）；强调动画八式（pulse 脉冲 / swing 摆动 / shake 抖动 / breathe 呼吸 / flash 闪烁 / tada 放大 / spin 旋转 / glow 发光，元素挂 `data-anim-emphasis` 循环播放）；标题文字动画四式（none 无动画默认 / char 逐字 / word 逐词 / line 逐行）；`ANIM: false` 时入场动画整份关闭（或放映时「开启」勾选框取消），所有选择浏览器记忆
- **自定义模板片段**（可选）：在 `resources/templates/` 下放 `my-*.html`（仅 body 内容片段，不含 html/head/script），生成时用户点名模板名即可套用；未点名用内置十六套模板
