# 登台 deck-stage 使用指南

登台（deck-stage）把日报/周报/年报的产出——或任何散装素材——转成专业 .pptx 演示文稿：常规页（数据卡/时间线/条目/柱图/饼图/折线）原生生成、完全可编辑，封面与结尾页用 HTML 截图贴图、视觉保真。页面与数据分离，五主题（深蓝科技/浅色商务/IDEA 黑亮/IDEA 白亮/温暖渐变）与报告同源，改主题只改一处。

## 怎么用

1. **一句话登台**：对 AI 说「把今天的日报转成 PPT」「把这份年报做成 pptx」，或直接给报告文件路径；没有现成报告时给主题大纲也行，AI 会先提炼要点
2. **三问交互**：AI 会先问你素材（指定目录/指定文件/贴文字/口述主题）→ 再报页结构大纲表给你增删改 → 最后问成片方式（一键成片 / 逐页确认）
3. **逐页确认**：选逐页确认时，每页先报排版方案（版式 + 内容 + 图表 + 演讲备注），你 OK 一页出一页；说「第 N 页改成 XX」重出单页、「换主题 biz」全局换、「加一页/删一页」改骨架
4. **自动排版**：AI 按报告结构自动映射版式——概览成数据卡页、成果成时间线页、条目成徽章页、提交节奏成柱图页，页数多了自动续页
5. **封面与结尾**：默认用深蓝面板封面模板（发光标题 + 数据卡），结尾「谢谢观看」；想用自己的图片说一声即可
6. **改风格**：说「用浅色商务主题」「用黑色主题（IDEA 黑亮）」——五套主题秒换；想永久换默认，改 `user-config.md` 的 THEME
7. **改内容**：生成后可直接在 PowerPoint/WPS 里编辑常规页（文本/饼图/折线都是原生元素）；想改截图页（封面/结尾）让 AI 重新生成即可
8. **落盘位置**：默认落到报告目录（`user-config.md` 的 DIR 可改）；说「放到桌面」即按临时要求落盘

## 提醒

- 转换不改原报告：md/HTML 原样保留，pptx 是新增产物
- 同名 pptx 不会覆盖旧文件，自动加日期后缀
- 生成全程离线，pptx 双击即开，可放心走内网流程
