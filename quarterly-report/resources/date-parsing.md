# 季度解析

把自然语言定位到目标季度区间。季度区间决定提交统计范围与目录/文件名。季度编号：Q1=1-3 月、Q2=4-6 月、Q3=7-9 月、Q4=10-12 月。

## 定位规则

| 用户说法 | 目标季度 | 区间 |
|:---|:---|:---|
| 2026年Q4 / 这个季度 / 写个季报（未指定）| 当前自然季度（如 2026-Q4）| 季首 ~ 今天（未过完则到「今天」）|
| 上季度 / Q3 的总结 | 上一自然季度 | 完整季度（07-01 ~ 09-30）|
| 近三个月 / 最近90天 | 滚动 90 天 | 今天 - 90 天 ~ 今天 |
| 2026-Q3 / 2026年第三季度（明确指定）| 指定季度 | 完整季度 |
| 今年 Q1-Q4 总结 / 全年季度回顾 | 全年按季度（成果段按 Q1/Q2/Q3/Q4 时间线）| 01-01 ~ 今天 |

- 「这个季度」以当前系统日期为准（11 月 12 日写季报 → Q4，区间 10-01 ~ 11-12，标题注明「截至 2026-11-12」）
- 目录：`{DIR}/2026-Q4/`（滚动 90 天用起始年月，如 08-14~11-12 → 2026-08，目录内文件名仍按目标季度或滚动区间）
- 文件名：`quarterly-report-2026-Q4.md/.txt/.html`、截图 `quarterly-report-2026-Q4-content.png`；滚动 90 天文件名用区间（如 `quarterly-report-2026-08-14~11-12.html`）；全年季度回顾文件名 `quarterly-report-2026-Q1-Q4.html`
- 同名目录已存在时直接复用（不重建、不清空），仅覆盖 FORMATS 清单内的同名文件；目录内其它文件一律保留不动（同目录下月报子目录互不干扰）
- 同一份季度总结重复生成默认直接覆盖；用户说「保留之前的/另存/不覆盖」时文件名追加时间戳（如 `quarterly-report-2026-Q4-1530.html`）
