# 落盘与 HTML（月度版式）

## 落盘

- FORMATS 默认 [md, txt, html, content-png]：md/txt/html 文件名 `monthly-report-YYYY-MM.<格式>`、截图 `monthly-report-YYYY-MM-content.png`；txt 为纯文本版；DISK: false 时全部不落盘
- 目录：`{DIR}/YYYY-MM/`（DIR 按系统取 DIR_MAC/DIR_WIN，不存在回退用户主目录下 reports）；目录已存在直接复用，只覆盖本清单内同名文件；目录内存在非本 skill 命名的其它文件时对话中提示用户「该目录内已有其它文件，本次月度总结已与它们并列存放，未做任何改动」
- 对话中照常输出 md 正文（不受 FORMATS 影响）；OPEN_HTML: true 且落盘了 html 时自动打开浏览器（macOS：open <html文件>；Windows PowerShell：Start-Process <html文件>）
- FORMATS 含 content-png 时生成内容区截图：只截四张分节卡片整体（月度概览/本月关键成果/问题与改进/下月计划，不含头部标题区/复制按钮/页脚，四周保留对称合适的外边距约 40px 留白）；html 内置 `?shot=content` 参数（页面 JS 检测后隐藏 header-card/footer（复制按钮在头部卡内随卡一并隐藏）、body 四周 padding 统一 40px，正常浏览不受影响）；用 Chrome headless 访问带参 URL 截图（路径按系统选：macOS=`/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`；Windows 按序探测 `C:\Program Files\Google\Chrome\Application\chrome.exe` → `C:\Program Files (x86)\Google\Chrome\Application\chrome.exe` → `%LOCALAPPDATA%\Google\Chrome\Application\chrome.exe`，经 node child_process 执行 `--headless --disable-gpu --no-sandbox --hide-scrollbars --user-data-dir=<临时目录> --screenshot=<png路径> --window-size=760,<估算高度> --virtual-time-budget=4000 "file:///<html路径>?shot=content"`（Windows 下 URL 写作 file:///C:/...，用 node url.pathToFileURL 生成），跑完删除临时目录；禁止用 `--headless=new`（单例模式会静默失败生成占位图）；若 Chrome 不存在则换 Edge（macOS=`/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge`；Windows=`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe` → `C:\Program Files\Microsoft\Edge\Application\msedge.exe`），都找不到时跳过截图并在对话注明）；高度按内容区实测基准估算（760 宽窄窗实测：概览 4 卡折 2 行、成果 5 条 + 2 占位周 + 热力图 170px、问题 2 条三环、计划 3 条 → 内容区约 2020px，图高 = 内容区 + 上下留白各 40px）：每增减 1 条成果条目 ±~85、1 条问题 ±~100、1 条计划 ±~90、概览数据卡每多一行 ±~105；实测高度显著高于按 65~70px/条的旧估算（数据卡 2 行排布 + 条目换行 + 卡片 padding），禁止低估导致截断，截图后用 Read 校验：四张卡片整体完整在图内、无头部/按钮/页脚残留、四周留白对称合适、不截断；底部留白过大减高度、截断加高度重截

## HTML 月度版式（深蓝面板体系，与日报/周报/年报同源）

- 复用日报/周报/年报深蓝面板视觉体系：背景 #0a1929 + SVG feTurbulence 微噪点（opacity .04）+ 三层科技底纹（.grid-pattern 60px 青色细网格 var(--scan-dim) + .stars 8 个 1-1.5px 星点白/青/紫/绿散落 + .scanlines 2px 周期扫描线 var(--scan-dim)）；图表渲染用 echarts@5.5.1（body 末尾主 script 之前引入 `<script src="https://cdn.jsdelivr.net/npm/echarts@5.5.1/dist/echarts.min.js"></script>`，页面唯一网络引用；离线/内网无外网加载失败时图表容器显示 data-off 降级提示文字、页面其余内容正常浏览不受影响）；除 echarts 外禁用任何 CDN 与外部网络引用（@import、外链 CSS/图片/网络字体一律禁止）；字体全用系统本地字体栈 ui-monospace/'SF Mono'/SFMono-Regular/Menlo/Consolas；颜色全部用 CSS 变量统一主题令牌：19 令牌 × 5 主题（tech 深蓝科技（默认，色值与旧 ask 色板一致）/biz 浅色商务/mono IDEA 黑亮（JetBrains New UI Dark 官方色系：编辑区 #1e1f22 + 面板 #2b2d30）/light IDEA 白亮（IntelliJ Light 官方色系：白编辑区 + 浅灰面板）/warm 温暖渐变，html[data-theme] 运行时切换；12 核心契约 --bg/--bg2/--panel/--panel-solid/--text/--muted/--accent/--accent2/--border/--glow/--title-grad/--tag-bg + 报告扩展 --glow-soft/--scan/--scan-dim/--heat/--green/--orange/--rose；生成时按 THEME 配置写 data-theme 定默认，页面右下角换肤坞五色点随点随换、localStorage 记忆、?shot 截图模式与打印隐藏）
- 头部卡片：标题按行业词典「标题」变量取词 + 月份前缀（如「2026-11 研发月度总结」；话术含职业词 → 该词条标题，未提职业 → 按 ROLE 画像匹配词条，词典外行业 → 「YYYY-MM 月度总结」兜底；词典标题行见 `resources/industry-dictionary.md`）+ 副标题（ROLE 画像或月份区间）+ 生成时间行；speccore ask 同款发光特效：四边 1px 青色浮光线 transparent→var(--accent)→transparent 整条平移扫动（上 scanX 左→右、右 scanY 上→下、下 scanX-rev 右→左、左 scanY-rev 下→上，四线同周期 3s linear 单向平移，亮段完整穿越卡片后消失于两端界外，卡片 overflow:hidden 裁剪；禁止自创 background-position 滚动/常驻辉光/往返摆动/亮段半嵌常驻变体）+ 顶部光斑 cardGlow（radial-gradient ellipse at 50% 10% var(--glow)→transparent 70%，opacity .5→1 + scale 1→1.6，transform-origin top center，3s 循环，头部与每张分节卡片内均放 .card-glow 层）+ 标题文字青色光晕呼吸（text-shadow 双圈 3s 循环）
- 四张分节卡片（实心深蓝底 #0b1e37 + 1px 白色微透细线 8px 周期淡条纹（repeating-linear-gradient(180deg, rgba(255,255,255,.012) 0 1px, transparent 1px 8px)，与日报/周报/年报同款，头部卡片同条纹） + 上下边缘 1px 微亮描边 #0f3350 + 圆角 6px + overflow:hidden + 保留阴影与 inset 内发光），左侧 8px 宽节色竖线贯穿整卡（box-shadow 0 0 12px 同色 30% 光晕），内容 padding-left 24px；节色：概览亮蓝 linear-gradient(180deg,#38bdf8,#0ea5e9) / 成果青绿 linear-gradient(180deg,#5eead4,#14b8a6) / 问题玫红 linear-gradient(180deg,#fda4af,#e11d48) / 计划橙 linear-gradient(180deg,#fdba74,#f97316)；节标题 18px 同色渐变 SVG 语义图标（概览=仪表盘、成果=奖杯、问题=三角警示、计划=日历）+ 文字微光晕（h2 flex gap 10px，标题色=节色亮端，同色双圈发光字 3s 呼吸 secGlow 动画，仅节标题文字发光，SVG 图标不加）
- 数字选择：用户口述的业务结果指标（响应时间/错误率/转化率/成功率等）优先写入，提交统计（提交数/文件数/行数）仅在无业务指标时兜底，两者都有时业务指标在前、提交统计后置或省略；数字凡有对比基准必带（环比上月/目标完成度至少其一，如「+18%」「达目标 90%」），无基准来源时不作要求 - 概览节：一句话 TL;DR 引言行 + 核心数据卡 3-5 张横排（.stat-card flex 均分：大数字 28px 渐变字 + 12px muted 标签 + 11.5px 环比小字「较上月：+18%」，上涨 --green 绿、下跌 --rose 红；数据卡左侧小色条同概览节色）
- 成果节：纵向时间线（.timeline 左侧 2px 青色竖线 + 周节点：W1/W2/W3/W4 圆形节点（节色渐变球 + 光晕，当前周节点加呼吸动画）+ 右侧内容（成果描述 15px + 量化小字 12px 青灰 + 周徽章 11px muted 胶囊）；周内多条共用周节点，条目间青色虚线分隔）
- 问题节/计划节：问题条目沿用 3D 立体圆球序号徽章（28px 白字，径向渐变球面（受光点 circle at 30% 28%，浅亮→主色→深色）+ inset 右下内暗影 + ::before 左上椭圆高光点 + 底部投影与同色光晕；问题玫红）；问题条三环展开：问题主行 + 影响行 12px 青灰「影响：xxx」+ 改进行 12px 青色「改进：」加粗前缀；计划条目卡（目标描述 15px + 量化指标加粗 + 周级行动节点小胶囊 11px（W1 起…/W2 完成…，muted 字 + 青色细边 var(--border) + 淡青底））
- 月度日历热力图（研发词条；其它词条按职业词典图表主题）：.cb-wrap 内 .ech echarts calendar heatmap 容器 170px 高（#heatChart）、整月日历格子、格色按当天提交数深浅渐变（var(--heat) 色系）、tooltip 显示「MM-DD · N 次提交」、周末格子 muted 弱化；置于成果节内时间线之后
- 内容区 .wrap width:clamp(640px, 60%, 1200px)（与日报/周报/年报同款自适应宽度，宽屏占 60% 不留大空边）+ 上下 padding 40px、左右 0 - 头部卡片内生成时间徽章下居中青色渐变 40px 大胶囊「一键复制」按钮（var(--accent)→var(--accent2)，30px 青色光晕，hover 45px 光晕上浮；flex 居中布局，内置 16px 内联 SVG 双矩形复制图标（白色 currentColor 描边、图标与文字 gap 8px、禁用 emoji 图标），复制成功后图标切对勾、文字变「已复制」）；复制源必须用 txt 文件内容（含换行、无 #/##/> 等 Markdown 符号，严禁用 md 内容当复制源）；JS 用 navigator.clipboard.writeText，失败回退隐藏 textarea + document.execCommand('copy')（兼容 file:// 打开）
- 入场动画：头部淡入下滑、四张卡片依次错峰上浮淡入（概览 0.13s/成果 0.26s/问题 0.4s/计划 0.54s）；滚动入场：初始视口外的卡片滚到视口才上浮渐显（html.js 门控 + IntersectionObserver，translate 独立属性不碰 transform——hover 3D 偏转零冲突，stagger 70ms 封顶 280ms、入场完即清 delay 不拖慢 hover 偏转，2s 兜底强制显示；无 JS/打印/截图模式一律全显）；窄屏收敛：<680px 视口 wrap 满宽流式、边距收窄、h1 统一 26px（clamp 640px 下限在窄窗不再横向溢出）；热力图 echarts 默认生长动画（对齐周报柱图）；?shot 截图模式 animation:false 直接渲染终态（headless 虚拟时间下动画帧不推进会停在初始帧导致截图空白）；echarts 容器 width:100% 窄屏自适应无需特化、按钮弹入；卡片入场动画 fadeDown/fadeUp/riseIn 的 fill-mode 必须用 backwards 严禁 both（both 使动画结束后最后一帧 transform:none 永久覆盖 hover 的 3D 偏转 transform，hover 偏转会完全失效）

- 卡片级 3D 微倾斜（严禁全页级 mousemove 倾斜）：每张卡片 hover 时仅该卡片随鼠标偏转（perspective(900px) + rotateY(calc(var(--mx,0)*2.5deg)) rotateX(calc(var(--my,0)*-2.5deg)) ±1.25° 极轻微，与 hover 上浮合并写同一条 transform 严禁拆两条相互覆盖）；JS 对每张卡片监听 mousemove 计算卡内相对位置（(clientX-rect.left)/rect.width*2-1 归一化 -1~1）只更新该卡 --mx/--my，mouseleave 归零回正，transition transform .18s 平滑；移动端无 mousemove 保持 0 不倾斜
- CRT 扫描光带（.scanband position:fixed、left:0/right:0、height:150px、linear-gradient(180deg,transparent,var(--scan-dim) 50%,transparent)、animation:scanMove 11s linear infinite（top -22%→112%）、pointer-events:none、z-index:998，置于 scanlines 之下一层）
- 禁止写 @media (prefers-reduced-motion: reduce) 禁用动画的媒体查询块（用户系统开启减少动画时该块会禁用全部动效）
- 页面 JS 需支持 `?shot=content` 参数（检测 location.search 含 shot=content 时给 header-card、footer 设 display:none（copy-wrap 在头部卡内随卡隐藏），body 四周 padding 统一 40px，供主体内容整体截图用、保证截图四周留白对称合适）
- 页脚 10px muted 文字（无分隔线、不加边框），署名固定 GENERATED BY SPECCORE TEAM · <年月>（动态跟随目标月份，如 GENERATED BY SPECCORE TEAM · 2026-11）
- 四段分节列表，条目保持中文顿号序号；md/txt 版同条目依次写，文本格式不变
