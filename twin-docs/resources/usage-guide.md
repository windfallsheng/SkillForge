# 孪生文档使用指南

## 能做什么

让中英双语文档保持「孪生」——翻译时术语对齐、结构逐项对应；之后改了一边，随时能查出另一边的差异清单并修复。

## 怎么用

1. 说「**出个英文版**」+ 指文件（或目录批量）→ 翻译 + 落盘 `{原名}.en.md`
2. 说「**检查中英同步**」→ 输出结构 diff 差异清单
3. 术语表：`docs/glossary.csv` 存在则严格按表取词；翻译完我附「建议加入术语表」清单
4. 改中文后说「英文版同步一下」→ 增量更新英文版

## 可改配置（user-config.md）

- `DIRECTION`：zh2en / en2zh
- `GLOSSARY_FILE`：术语表位置
- `LINK_RULE`：顶部互链规则
- `SYNC_MODE`：只翻译 / 只检查 / 都做

## 使用提示

- 命令、路径、文件名、版本号不会被翻译
- 每次改完中文文档，顺手说一句「检查同步」，双语永不漂移
