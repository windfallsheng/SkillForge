# 翻译与排版对齐（阶段 2）

## 翻译纪律

- **不译清单**：技术术语、命令、路径、文件名、版本号、代码标识符一律保留原文；中文标题序号保留（一、二、→ 1. 2.）
- **语义对齐**：段落按语义翻译（中英文语序各自自然），不逐字硬译；同一段信息量对等，中文有的一英文必须有
- **术语一致**：同一概念两份文档同一译法（术语表优先，见 glossary.md）
- **样式基调**：STYLE: concise 时用短句直译；literal 时保留原文语序更贴近

## 结构对齐（逐项对应）

- 标题层级与数量一致；表格行列一致（表头翻译、单元格内容按不译清单规则）
- 代码块原样保留（注释可译可不译，保持与原文一致即可）；列表条目一一对应
- 链接：markdown 链接目标路径改为对应英文文件（`docs/x.md` → `docs/x.en.md`）；锚点标题按英文标题改写并保持可达
- 顶部互链：LINK_RULE: mutual 时中文文档顶部加「English | [README.en.md](README.en.md)」样式互链行，英文版加反向链接

## 落盘

- 命名：`{原名}.en.md`（zh2en）或去掉 `.en` 后缀（en2zh）；与源文件同目录
- 落盘完成后对话报告落盘位置：完整路径 + 简要说明（新增 / 更新）
