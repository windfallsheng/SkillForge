# 术语对齐（阶段 1）

## 术语表机制

1. 翻译前先探测 `GLOSSARY_FILE`（CSV 三列：`term,zh,en`，UTF-8）——存在则全文 Read，翻译时术语严格按表取词
2. 不存在时按默认规则翻译：技术术语（API / cache / pipeline 等）保留原文，行业通用词用通行译法，同一概念全文同一译法
3. 顺带收集：翻译中遇到的「有固定译法倾向」的术语，对话末尾附「建议加入术语表」清单（term,zh,en 三列），用户点头后写入 GLOSSARY_FILE（不存在则创建）

## 术语表读写纪律

- 术语表以 term 为键唯一；新增不改旧行（避免旧文档引用的译法漂移）
- 术语命中大小写敏感；表内 zh/en 均非空才算有效行
