# 同步自检（阶段 3）

翻译落盘后（或用户只要求检查时），对源文件与译文做结构 diff：

## 检查项

1. **标题树对齐**：提取两份文档全部标题（`grep -n "^#\{1,6\} " 文件`），层级与数量一一对应，缺失处列出
2. **行数比**：译文行数与源文比值 < 1.5（中英文行数天然有差，超出说明有整段遗漏或冗余）
3. **关键词命中**：术语表内术语在译文中的出现次数与源文一致（±0 才算通过）
4. **链接可达**：译文内相对链接目标文件真实存在；锚点与英文标题对应
5. **不译项回检**：译文全文 grep 命令 / 路径 / 版本号，与源文一致无被误译

## 输出

差异清单按「缺失 / 多出 / 不一致」三类列出，逐项给修复建议；全过则报告「孪生对齐 ✅」。发现问题时主动修复（SYNC_MODE: both 默认修复后复检）。
