# 清洗与结构化落盘（阶段 2-3）

## 清洗预设（CLEAN_PRESET）

**standard（标准）**：去空行 → 去首尾空格 → 去除全空列 → 空单元格留空不编造 → 数值列类型规整（去千分位逗号 / 百分号转小数按列语义定，语义不明不动）→ 按 ID_FIELDS 去重（保留首条）
**minimal**：只转格式不洗内容，原样落盘

## 清洗纪律

- **动手前列清单**：将执行的清洗项逐条列出（「去重：按 姓名+日期 主键，删除 N 条」）给用户看，改口即调整，确认后执行
- **变更留痕**：每条清洗操作记录「做了什么 + 影响多少行」进变更清单（最终并入概览报告）
- **原始文件永不修改**：清洗结果写新文件；不编造缺失值；语义不明先问

## 结构化落盘

- OUT_FORMAT: json → `cleaned/data.json`（数组结构，字段保持原表头清洗后的名称）；csv → `cleaned/data.csv`（UTF-8 BOM 便于 Excel 打开）；both 两份都出
- DIR: auto 时落盘到源文件同目录 `cleaned/` 子目录；目录已存在直接复用
- **落盘完成后对话报告落盘位置**：完整路径 + 行数列数 + 清洗变更清单摘要
