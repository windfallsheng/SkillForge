# 技能体检使用指南

## 能做什么

给已安装技能做全身体检：frontmatter 完整性、resource 引用可达、配置版本与升级保护、触发词、占位符残留，HTML 技能另查字体侵权 / 多文件隔离 / 产物版本戳 / 入场动画兜底。输出三段式报告（✅ 健康 / ⚠️ 警告 / 🟡 问题），每条带文件与行级定位。

## 怎么用

1. 说「**体检一下我的技能**」→ 我扫描技能目录，列发现清单让你确认范围
2. 逐项检查后输出三段式报告，问题附修复建议
3. 说「能修的帮我修」→ 我列可顺修清单，你勾选后逐项修并复检

## 可改配置（user-config.md）

- `TARGET`：体检目录（auto 自动探测）
- `CHECKS`：full 全项 / slim 核心项
- `FIX`：ask 先问再修 / off 只报告

## 使用提示

- 检查标准与 meta-forge 锻造规范同源，检出的问题按规范修复后即达标
- 每个新技能装完后体检一次，问题不过夜
