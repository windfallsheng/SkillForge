## 段要点

- 年度概览：一句话 TL;DR + 核心数据卡 3-6 项；数字凡有对比基准必带（同比/目标完成度至少其一）；可带同比小字（「较去年：+18%」）
- 核心成果与里程碑：按季度（Q1/Q2/Q3/Q4）时间线 8-12 项，每项：成果描述 20-40 字 + 所属季度 + 量化结果 + 价值归因（做了什么→改变了什么→与年度目标的关联）；里程碑优先，日常任务不逐条列；未过完的季度注明「截至当前」
- 经验与成长：3-5 条，每条一句话（「沉淀了 XX 方法」「掌握了 XX」）；强调可复用，不写「完成了 XX」这类成果句（归段二）
- 不足与反思：2-4 条三环（问题+影响+改进）；改进含可验证动作与时间节点（如「Q1 引入 code review 制度，季度缺陷率降到 X%」）；无真实不足才写「暂无」
- 新年展望与规划：年度目标 3-5 项（目标描述 + 可量化指标 + 完成标准），每项带分季度行动节点（Q1 起…Q2 完成…）；目标与不足改进方向呼应
- 序号用中文顿号（1、2、3）；段内条目数按上述区间；不足处写「暂无」
