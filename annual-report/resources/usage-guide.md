# 年度总结使用指南

## 能干什么

把一年的工作沉淀成五段式年度总结：年度概览（一句话 + 核心数据卡）/ 核心成果与里程碑（季度时间线）/ 经验与成长 / 不足与反思 / 新年展望与规划。适配各行业：内置 12 行业职业词典，报职业自动换术语与指标；不报职业按你的默认角色画像生成。

## 三种使用方式

1. **git 全年聚合**（有代码仓库）：自动统计全年提交数、增删行数、月度分布、版本里程碑，结合你口述的大事生成
2. **纯文字整理**：把年度大事、成果、感悟直接说给我或发文字
3. **图片/文件整理**：发总结草稿、聊天记录、日报周报文件，我提取要点

三者可混用，有 git 就用 git 数据，没有也能写。

## 常用说法

- 「写个年度总结」/「2026 年年度总结」→ 当前年或指定年
- 「去年的年度总结」/「近一年的总结」→ 去年或滚动 12 个月
- 「以销售经理的身份写年度总结」→ 临时换职业词条
- 「以后默认用 XX 角色」→ 永久换默认角色
- 「只要 md」「别开浏览器」「写到桌面」→ 临时改落盘行为
- 「以后都用这个模板」→ 永久自定义模板

## 输出

对话直接出正文；默认落盘 annual-YYYY/ 目录下的 md/txt/html 三件 + 内容区截图，并自动打开 html（深蓝面板年度版式：发光头部、数据卡、季度时间线）。
