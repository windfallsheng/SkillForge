# 落盘与 HTML（年度版式）

## 落盘

- FORMATS 默认 [md, txt, html, content-png]：md/txt/html 文件名 `annual-report-YYYY.<格式>`、截图 `annual-report-YYYY-content.png`；txt 为纯文本版；DISK: false 时全部不落盘
- 目录：`{DIR}/annual-YYYY/`（DIR 按系统取 DIR_MAC/DIR_WIN，不存在回退用户主目录下 reports）；目录已存在直接复用，只覆盖本清单内同名文件；目录内存在非本 skill 命名的其它文件时对话中提示用户「该目录内已有其它文件，本次年度总结已与它们并列存放，未做任何改动」
- 对话中照常输出 md 正文（不受 FORMATS 影响）；OPEN_HTML: true 且落盘了 html 时自动打开浏览器（macOS：open <html文件>；Windows PowerShell：Start-Process <html文件>）
- FORMATS 含 content-png 时生成内容区截图：只截五张分节卡片整体（年度概览/核心成果与里程碑/经验与成长/不足与反思/新年展望与规划，不含头部标题区/复制按钮/页脚，四周保留对称合适的外边距约 40px 留白）；html 内置 `?shot=content` 参数（页面 JS 检测后隐藏 header-card/footer（复制按钮在头部卡内随卡一并隐藏）、body 四周 padding 统一 40px，正常浏览不受影响）；用 Chrome headless 访问带参 URL 截图（路径按系统选：macOS=`/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`；Windows 按序探测 `C:\Program Files\Google\Chrome\Application\chrome.exe` → `C:\Program Files (x86)\Google\Chrome\Application\chrome.exe` → `%LOCALAPPDATA%\Google\Chrome\Application\chrome.exe`，经 node child_process 执行 `--headless --disable-gpu --no-sandbox --hide-scrollbars --user-data-dir=<临时目录> --screenshot=<png路径> --window-size=760,<估算高度> --virtual-time-budget=4000 "file:///<html路径>?shot=content"`（Windows 下 URL 写作 file:///C:/...，用 node url.pathToFileURL 生成），跑完删除临时目录；禁止用 `--headless=new`（单例模式会静默失败生成占位图）；若 Chrome 不存在则换 Edge（macOS=`/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge`；Windows=`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe` → `C:\Program Files\Microsoft\Edge\Application\msedge.exe`），都找不到时跳过截图并在对话注明）；高度按内容区估算（body 上下留白~80 + 概览节(标题45+数据卡~90+45) + 里程碑节(标题45+条目数×~65+40) + 成长节/反思节/展望节(各45+条目数×~70+40) + 各卡片 margin-bottom 18 + 余量~15，底部留白仅 body 下 padding 40px、与顶部对称），截图后用 Read 校验：五张卡片整体完整在图内、无头部/按钮/页脚残留、四周留白对称合适、不截断；底部留白过大减高度、截断加高度重截

- 复用日报/周报深蓝面板视觉体系：背景 #0a1929 + SVG feTurbulence 微噪点（opacity .04）+ 三层科技底纹（.grid-pattern 60px 青色细网格 var(--scan-dim) + .stars 8 个 1-1.5px 星点白/青/紫/绿散落 + .scanlines 2px 周期扫描线 var(--scan-dim)）；图表渲染用 echarts@5.5.1（body 末尾主 script 之前引入 `<script src="https://cdn.jsdelivr.net/npm/echarts@5.5.1/dist/echarts.min.js"></script>`，页面唯一网络引用；离线/内网无外网加载失败时图表容器显示 data-off 降级提示文字、页面其余内容正常浏览不受影响）；除 echarts 外禁用任何 CDN 与外部网络引用（@import、外链 CSS/图片/网络字体一律禁止）；字体全用系统本地字体栈 ui-monospace/'SF Mono'/SFMono-Regular/Menlo/Consolas；颜色全部用 CSS 变量统一主题令牌：19 令牌 × 5 主题（tech 深蓝科技（默认，色值与旧 ask 色板一致）/biz 浅色商务/mono IDEA 黑亮（JetBrains New UI Dark 官方色系：编辑区 #1e1f22 + 面板 #2b2d30）/light IDEA 白亮（IntelliJ Light 官方色系：白编辑区 + 浅灰面板）/warm 温暖渐变，html[data-theme] 运行时切换；12 核心契约 --bg/--bg2/--panel/--panel-solid/--text/--muted/--accent/--accent2/--border/--glow/--title-grad/--tag-bg + 报告扩展 --glow-soft/--scan/--scan-dim/--heat/--green/--orange/--rose；生成时按 THEME 配置写 data-theme 定默认，页面右下角换肤坞五色点随点随换、localStorage 记忆（键按页面路径隔离、多份产物互不串台）、?shot 截图模式与打印隐藏）
