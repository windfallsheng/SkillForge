# prompts.json 结构规范与维护操作

## Schema（version 1）

```json
{
  "version": 1,
  "groups": [
    { "id": 1762500000000101, "name": "写作输出", "icon": "✍️" }
  ],
  "prompts": [
    {
      "id": 1762500000123456,
      "group": 1762500000000101,
      "title": "日报速写",
      "content": "提示词正文，支持 {变量} 插值占位……",
      "tags": ["日报", "工作"],
      "order": 1,
      "favorite": true,
      "createdAt": "2026-11-10 14:23:45",
      "updatedAt": "2026-11-10 16:05:12"
    }
  ]
}
```

## 字段约定

- `groups[].id`：16 位纯数字主键（雪花 ID，见下「id 生成规则」），全库唯一；`name` 中文显示名；`icon` 一个 emoji
- `prompts[].id`：16 位纯数字主键（雪花 ID），全库唯一，删除后不复用
- `prompts[].group`：引用组的数字 id，写回前逐一校验
- `prompts[].order`：组内排序权重，从 1 递增且尽量连续；重排时按新顺序整体重写（数字 id 天然按时间有序，可作辅助参考）
- `prompts[].favorite`：收藏星标（页面点星为本地态，指令「收藏/取消收藏 XX」由 AI 落盘）
- `prompts[].tags`：1-3 个短标签，用于搜索与归类
- `prompts[].createdAt`：添加时间（YYYY-MM-DD 或 YYYY-MM-DD HH:mm:ss，**新增提示词必写到时分秒**）；旧数据可无此字段或仅日期（页面按 order 兜底排序，数字 id 时间序可辅助）
- `prompts[].updatedAt`：最近一次内容修改时间（格式同 createdAt，写到时分秒）；新增不写、首次修改才写，仅重排 order 不更新

### id 生成规则（雪花变体）

16 位纯数字 = 13 位毫秒时间戳 + 3 位随机数，如 `1762500000123456`：

- AI 生成：把当前日期时间换算成 13 位毫秒时间戳（精确到秒即可，毫秒三位自选），末尾拼 3 位随机数（000~999 自选）；与现有 id 重复时只换随机段（同一毫秒不同随机数即不同 id）
- 保证：不同时刻生成必不同 → 导出数据再导入不冲突；删除不复用；纯数字比 UUID 短一半，AI 抄写定位不易错
- 存量兼容：早期版本 id 可能是「组 slug+序号」字符串（如 w05），兼容保留不必迁移（id 仅作唯一键）；新生成的组/提示词一律用数字雪花 id

## 维护操作规则

- **新增提示词**：用户说「把 XX 加到锦囊的写作输出分组」→ 补一条 prompts 记录（id 按雪花规则生成数字主键、group/title/content/tags/order/favorite/createdAt 齐全，createdAt 写到时分秒）；未指定分组时，优先选语义最匹配的现有分组，实在没有才新建分组并先询问
- **修改**：定位 id 或标题，只改用户指定的字段；「修改锦囊里『日报速写』的内容」→ 整段替换 content；改标题/分组/内容/标签时把 updatedAt 更新为当前时间（格式同 createdAt，写到时分秒）
- **删除**：删 prompts 条目；删分组前须先处理组内条目（移组或一并删除，需与用户确认）
- **排序与分组**：用户粘贴「复制变更指令」文本 → 先按「分组调整」节改各条 `group`（把「X」从「A」移到「B」），再按「各组顺序」节每组列表顺序重写 `order`；指令含「未保存」提示时，说明用户拖拽后未复制最新指令，以指令内容为准
- **新建分组**：id 按雪花规则生成数字主键，name 中文，icon 一个 emoji
- **写回格式**：UTF-8、2 空格缩进、末尾换行；不压缩不重排无关字段
- **双写者纪律**：页面（授权目录时）与 AI 都会写本文件——任何一方写回前必须重读最新内容再合并修改，严禁基于旧内容整体覆盖

## 页面排序模式（AI 只负责 order、createdAt 与 updatedAt，其余为浏览器本地态）

| 模式 | 依据 | 谁维护 |
|:---|:---|:---|
| 最新添加（默认） | `createdAt` 倒序，全时间范围 | AI 写 createdAt |
| 最近使用 | 复制时页面自动记 `lastUsed` 时间戳，倒序 | 页面自动（浏览器本地态） |
| 使用频率 | 复制时页面自动累加 `useCount`，倒序 | 页面自动（浏览器本地态） |
| 手动顺序 | `order` 升序 | AI 按「复制变更指令」重写 order |

- 排序模式选择、使用统计、收藏均存浏览器本地（IndexedDB + localStorage 镜像），**不写数据文件（prompts.json）**，AI 无需落盘这些字段
- 用户在「最近添加/最近使用/使用频率」模式下拖动卡片或点 ▲▼，页面自动切回「手动顺序」并提示；随后按指令重写 order
- 写 order 时注意：手动顺序只约束组内，跨组顺序无意义（页面按分组展示）
