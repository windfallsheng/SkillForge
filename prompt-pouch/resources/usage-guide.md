# 锦囊使用指南

锦囊（prompt-pouch）是一个本地 HTML 提示词管理台：暖棕金默认配色，内置五套主题（暖棕金/深蓝科技/IDEA 黑亮/IDEA 白亮/薄荷绿，右下角换肤坞随时切换），分组侧栏 + 搜索 + 卡片网格（背景四层科技氛围与卡片细纹，与日报/周报/年报同源），妙计入囊、随取随用。页面与数据分离——页面可直写、AI 可代笔（双笔协作），你只管说，刷新即见。

## 怎么用

1. **打开页面**：对 AI 说「打开锦囊」即可（自动起服务并打开浏览器）；手动方式：`cd <目录> && python3 -m http.server 8933`（Windows 用 `py -m http.server`），浏览器访问 `http://localhost:8933/prompt-pouch.html`（HTTP 方式自动读 data/prompts.json；file:// 直开时浏览器会拦截文件读取——已授权目录则刷新自动直读 data/prompts.json，权限需重新确认时点徽标「🔓 恢复数据」一键续权（免重新选目录），读不到则回退本地快照/镜像、再回退内置示例，点页面「💾 授权目录」即可载入你的数据，但仍推荐 HTTP 打开）
2. **添加提示词**：页面点「＋ 新增提示词」填表保存（已授权目录即写即存）；或对 AI 说「把 XX 加到锦囊的写作输出分组」（不说分组也行，AI 会列出现有分组让你选；分组不存在时会问你是否新建）
3. **查看与修改**：卡片正文超长只显示前三行，点「👁 详情」弹窗看全文（超长限高滚动，弹窗右上角 ⛶ 可全屏），弹窗内可直接「⧉ 复制」或「✎ 修改」，并附时间线——创建时间、上次修改时间（修改过才显示）、最近使用时间（用过才显示）；卡片上也能直接点「✎」改完保存；或对 AI 说「修改锦囊里『日报速写』的内容」，改后刷新
4. **删除**：页面点卡片「🗑」；或对 AI 说「删掉锦囊里『XX』这条」
5. **排序与移组**：顶栏「排序」切换四种方式——最新添加（默认）/ 最近使用 / 使用频率 / 手动顺序；想手动排时拖动卡片或点 ▲▼（自动切回手动），点卡片 ⇄ 可把提示词移到其它分组；已授权目录时排序/移组 2 秒内自动保存，未授权时点「📋 复制变更指令」把指令发给 AI 落盘；复制过提示词后卡片右上角会显示「⧉ N 次 · 最近时间」（最近使用/使用频率排序即按复制统计）；AI 落盘后回页面点「✓ 已落盘」清除未保存标记
6. **收藏**：卡片右上角星标，收藏/取消收藏指令由 AI 同步到数据文件
7. **分组管理**：「全部」行右侧「＋」小图标新建分组；悬停分组名出现「✎ 改名 / 🗑 删除」（组内还有提示词时不允许删，先移出或删条目）；重名分组会提示；新建/编辑分组时图标输入框下方有快捷 emoji 面板（点击即填入、选中高亮，输入框仍可手输/粘贴任意 emoji）
8. **标签全交互**：点卡片标签立即按标签筛选（顶栏出现「🏷 标签」胶囊，点 ✕ 或再点同标签取消，切分组自动清除，与搜索叠加）；标签悬停出「✕」点它直接删除该标签；标签不满 3 个时悬停出「＋」快速加标签（多个用逗号分隔）——已授权目录即写即存，未授权时操作指令复制给 AI 落盘
9. **分组排序**：左侧分组条可直接拖拽调整顺序（已授权目录即写即存，未授权时指令自动复制给 AI 落盘）
10. **导入 / 导出**：顶栏「⤓ 导出」把当前全部数据下载为 JSON 备份文件（文件名带时间戳）；「⤒ 导入」选择 JSON 文件整库覆盖现有数据（导入前自动备份，可从「↩ 恢复」回滚；未授权目录时导出仍可用、导入需先授权）
11. **取用（先查后用）**：对 AI 说「锦囊里有什么适合写产品周报的？」——AI 读数据文件按标题/正文/标签/分组语义匹配，列候选清单（序号 | 标题 | 分组 | 匹配理由），选定某条即直接按模板执行（含 {变量} 按上下文填充）或输出正文供复制；日常任务（写日报/周报/复盘/邮件等）AI 会先静默扫一眼锦囊——有现成模板就告知「锦囊里有现成的 XX 模板，我来套用」，没有就正常完成、完成后轻问一句「这次的写法要不要收进锦囊？下次直接复用」；说「不用查锦囊」可跳过

## 典型使用场景

- **对话沉淀**：对 AI 说「把上一轮对话存进锦囊」「把最近几轮对话整理进锦囊」「把最近一小时聊的内容存进锦囊」——AI 先把对话提炼成条目清单（标题/正文/智能标签/插值泛化建议），你确认条目后再按现有分组推荐归类（装不下的推荐新建分组），确认后一次性入囊
- **从零开始**：还没创建锦囊时直接说「把 XX 存进锦囊」——AI 会先确认目录并引导创建页面（可选示例数据），随后无缝衔接入囊流程
- **对话删除与回退**：对 AI 说「删掉锦囊里 XX 分组 / XX 这条」——先确认、落盘前自动留 `prompts.json.bak-时间戳` 备份；删错说「回退/恢复锦囊数据」，列出备份档供选档恢复（恢复前再备份当前版，双保险）
- **换电脑迁移**：旧机「⤓ 导出」JSON 文件 → 新机「⤒ 导入」整库恢复（含分组与标签）；收藏、排序等页面本地态存浏览器本地（随页面 pouch-id 身份），不随 JSON 迁移
- **主动取用**：说「锦囊里有什么适合 XX 的？」「用锦囊里那条模板」——AI 先查后用，命中即复用、未命中完成后再问是否沉淀入囊；写日报/周报前让 AI 先翻锦囊，往往有现成模板可套
- **调优与效果反馈**：说「这条不好用，帮我改」——AI 读原文 + 你的反馈 → 给改版对照（旧 → 新）→ 确认后写回（更新时间线可见）；用完说「这条好用」→ AI 在数据里记一行可选 notes（页面详情弹窗「📝 使用心得」只读展示），给下次取用提供参考

## 特色功能

- **搜索高亮**：搜索框输入关键词，命中卡片的标题/正文/标签中匹配词以主题色徽标高亮（五主题自适应）；命中落在正文三行折叠区之外时，卡片顶部提示「正文命中，详见详情」，点开详情弹窗全文同样高亮
- **{变量} 插值**：内容含花括号占位（如「{功能名}」）的提示词，点复制会自动弹出填充面板，填入变量后实时预览再复制（预览区加高展示，面板右上角 ⛶ 可全屏）
- **自动备份（默认开启）**：数据一有变更 2 秒内自动备份——首次变更会请求授权写入 prompt-pouch.html 所在目录（弹窗选同目录即可，选一次后浏览器记住），写 backup/pouch-backup.json 并滚动保留上一版 .prev.json；未授权或浏览器不支持时自动降级为本地快照（浏览器内保留最近 5 份），页内「↩ 恢复」均可一键回滚；顶栏「📂 换目录」可随时重新配置备份目录；AI 代笔修改（对话中说增删改）落盘前也会在 data/ 目录留 `prompts.json.bak-时间戳`，说「回退/恢复锦囊数据」即可选档回滚
- **统一确认弹框**：删除提示词/分组、覆盖导入、恢复备份、授权与换备份目录等需要确认的操作，都用页内统一样式的确认弹框（不再弹浏览器原生对话框）；删除/覆盖/恢复等危险操作为红调按钮，Esc 或点遮罩均可取消
- **详情弹窗**：点卡片「👁 详情」弹出全文查看（超长内容限高 56vh 内滚动），带复制与修改入口，右上角 ⛶ 可全屏，附时间线（创建 / 上次修改 / 最近使用）；含 {变量} 的模板会在弹窗里标出变量清单，复制时自动进入填充面板
- **⛶ 弹窗全屏**：详情 / 变量填充 / 新增编辑三个弹窗右上角都有 ⛶ 按钮，一键切换全屏（96vw × 96vh）——长内容一览无余，再点 ⤡ 或关闭弹窗自动还原；填充面板全屏时顶部预览与底部实时结果按弹性分配剩余高度，变量少时两区都放大、变量多时自动收缩且滚动兜底
- **📝 使用心得**：AI 代笔维护的可选 notes 字段——用完说「这条好用」即可记录一行心得，详情弹窗「📝 使用心得」区只读展示（无心得不显示）；页面表单不编辑此字段，由对话维护，旧数据无此字段完全兼容
- **页面直写（双笔）**：页面增删改直接写入 data/prompts.json（与自动备份共用同一目录授权）；未授权时自动降级——生成操作指令复制到剪贴板，粘贴给 AI 落盘
- **侧栏局部滚动**：分组较多时，左侧「收藏 + 分组列表」区域独立滚动（窄滚动条，滚动区最大高度 = 屏幕高度减去顶栏、「全部」行与底部说明卡），「＋ 新建分组」在「全部」行右侧不随滚动、「全部」固定不滚；底部「锦囊用法」说明卡完整展示不裁剪，侧栏随页面整体滚动即可读完；窄屏下自动恢复平铺排列
- **批量整理入囊**：把一堆文字/文件交给 AI，或说「把最近对话框内容整理进锦囊」——两段确认：先定条目（AI 默认智能打标——每条自动配 1-3 个语义标签，可改可删；含具体词的可泛化为 {变量} 插值，附改写示例）→ 再定分组（归组理由 + 装不下的推荐新分组名），都确认后一次性写入；条目少（≤3 条）两段合一
- **标签全交互**：点标签即筛选（顶栏胶囊一键清除，再点取消，切分组自动清除，与搜索叠加）；标签悬停「✕」删、「＋」加（最多 3 个），授权目录即写即存，未授权指令交 AI
- **导入 / 导出 JSON**：顶栏「⤓ 导出」一键下载全量数据为 JSON 备份文件（文件名带时间戳）；「⤒ 导入」选择 JSON 文件整库覆盖（导入前自动备份、可恢复）；未授权目录时导出仍可用、导入需先授权
- **分组拖拽排序**：左侧分组条拖拽即可重排分组顺序（授权目录即写即存；未授权时生成「请把锦囊分组顺序调整为…」指令复制给 AI 落盘）
- **四种排序**：最新添加（按添加时间倒序，全时间范围）/ 最近使用 / 使用频率 / 手动顺序；排序选择会自动记住，下次打开不变
- **使用统计**：每次点复制，页面自动记录该提示词的最近使用时间与累计次数（存浏览器本地），供「最近使用」「使用频率」排序使用，数据文件不写这些字段
- **修改时间**：每次修改提示词（页面直写或 AI 代笔），数据文件会记下 updatedAt 修改时间，详情弹窗时间线可见；新增不写、仅排序不写
- **本地态**：收藏、排序选择、使用统计、主题选择存浏览器本地（IndexedDB 库名 + localStorage 镜像键均按页内嵌唯一 ID 命名空间隔离：多份锦囊互不串台、改名/移动目录不丢、复制文件副本=同一身份共享数据），刷新不丢，不写数据文件

## 提醒

- 数据在 data/prompts.json（备份在 backup/ 目录）；迁移/备份复制 data/ 与 backup/ 两个目录即可
- 「⤓ 导出」的 JSON 文件可直接在另一台电脑「⤒ 导入」整库恢复（含分组与标签）
- 页面样式与脚本升级由仓库 reference.html 重新复制完成，不影响你的数据

## 效果不对怎么办

- 页面效果不对（布局乱 / 卡片显示异常 / 搜索筛选失灵 / 主题错乱），对 AI 说「锦囊页面有 XX 问题，对照参考模板修复」，把问题描述清楚（什么操作、什么现象，能截图最好）
- 本技能的设计标准答案就在技能目录里：`resources/reference.html`（页面样式真相源），AI 修复时以此为唯一对照
- AI 的处理流程固定：先查数据文件 data/prompts.json 是否合法 → 再对照 reference.html 定位是页面问题还是数据问题 → 页面问题以 reference 为准重新复制页面（你的数据一概不动）、数据问题只修 json → 自动验证页面零报错、卡片数正确，截图自证
- 说「打开锦囊」发现打不开 / 白屏：优先说清报什么错，AI 会先确认是否按 HTTP 方式启动（file:// 直开会退回缓存快照，不是页面坏了）
