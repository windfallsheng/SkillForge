# 锦囊使用指南

锦囊（prompt-pouch）是一个本地 HTML 提示词管理台：深棕金配色，分组侧栏 + 搜索 + 卡片网格，妙计入囊、随取随用。页面与数据分离——页面可直写、AI 可代笔（双笔协作），你只管说，刷新即见。

## 怎么用

1. **打开页面**：对 AI 说「打开锦囊」即可（自动起服务并打开浏览器）；手动方式：`cd <目录> && python3 -m http.server 8933`（Windows 用 `py -m http.server`），浏览器访问 `http://localhost:8933/prompt-pouch.html`（HTTP 方式才能读 prompts.json；file:// 直开会回退浏览器缓存快照，不推荐）
2. **添加提示词**：页面点「＋ 新增提示词」填表保存（已授权目录即写即存）；或对 AI 说「把 XX 加到锦囊的写作分组」（不说分组也行，AI 会列出现有分组让你选；分组不存在时会问你是否新建）
3. **查看与修改**：卡片正文超长只显示前三行，点「👁 详情」弹窗看全文（超长限高滚动），弹窗内可直接「⧉ 复制」或「✎ 修改」，并附时间线——创建时间、上次修改时间（修改过才显示）、最近使用时间（用过才显示）；卡片上也能直接点「✎」改完保存；或对 AI 说「修改锦囊里『日报速写』的内容」，改后刷新
4. **删除**：页面点卡片「🗑」；或对 AI 说「删掉锦囊里『XX』这条」
5. **排序与移组**：顶栏「排序」切换四种方式——最新添加（默认）/ 最近使用 / 使用频率 / 手动顺序；想手动排时拖动卡片或点 ▲▼（自动切回手动），点卡片 ⇄ 可把提示词移到其它分组；已授权目录时排序/移组 2 秒内自动保存，未授权时点「📋 复制变更指令」把指令发给 AI 落盘；复制过提示词后卡片右上角会显示「⧉ N 次 · 最近时间」（最近使用/使用频率排序即按复制统计）；AI 落盘后回页面点「✓ 已落盘」清除未保存标记
6. **收藏**：卡片右上角星标，收藏/取消收藏指令由 AI 同步到数据文件
7. **分组管理**：侧栏底部「＋ 新建分组」；悬停分组名出现「✎ 改名 / 🗑 删除」（组内还有提示词时不允许删，先移出或删条目）；重名分组会提示

## 特色功能

- **{变量} 插值**：内容含花括号占位（如「{功能名}」）的提示词，点复制会自动弹出填充面板，填入变量后实时预览再复制
- **自动备份（默认开启）**：数据一有变更 2 秒内自动备份——首次变更会请求授权写入 prompt-pouch.html 所在目录（弹窗选同目录即可，选一次后浏览器记住），写 pouch-backup.json 并滚动保留上一版 .prev.json；未授权或浏览器不支持时自动降级为本地快照（浏览器内保留最近 5 份），页内「↩ 恢复」均可一键回滚；顶栏「📂 换目录」可随时重新配置备份目录
- **详情弹窗**：点卡片「👁 详情」弹出全文查看（超长内容限高 52vh 内滚动），带复制与修改入口，附时间线（创建 / 上次修改 / 最近使用）；含 {变量} 的模板会在弹窗里标出变量清单，复制时自动进入填充面板
- **页面直写（双笔）**：页面增删改直接写入 prompts.json（与自动备份共用同一目录授权）；未授权时自动降级——生成操作指令复制到剪贴板，粘贴给 AI 落盘
- **批量整理入囊**：把一堆文字/文件交给 AI，或说「把最近对话框内容整理进锦囊」，AI 按现有分组归档、装不下的推荐新分组，你调整确认后一次性写入
- **四种排序**：最新添加（按添加日期倒序，全时间范围）/ 最近使用 / 使用频率 / 手动顺序；排序选择会自动记住，下次打开不变
- **使用统计**：每次点复制，页面自动记录该提示词的最近使用时间与累计次数（存浏览器本地），供「最近使用」「使用频率」排序使用，数据文件不写这些字段
- **修改时间**：每次修改提示词（页面直写或 AI 代笔），数据文件会记下 updatedAt 修改日期，详情弹窗时间线可见；新增不写、仅排序不写
- **本地态**：收藏、排序选择、使用统计存浏览器本地（IndexedDB + localStorage 镜像），刷新不丢，不写数据文件

## 提醒

- 数据只在同目录 prompts.json 一个文件里，迁移/备份复制它即可
- 页面样式与脚本升级由仓库 reference.html 重新复制完成，不影响你的数据
