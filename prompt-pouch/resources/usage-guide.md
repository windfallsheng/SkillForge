# 锦囊使用指南

锦囊（prompt-pouch）是一个本地 HTML 提示词管理台：深棕金配色，分组侧栏 + 搜索 + 卡片网格，妙计入囊、随取随用。页面与数据分离——**AI 是唯一的笔**，你只管说，刷新即见。

## 怎么用

1. **打开页面**：`cd <目录> && python3 -m http.server 8933`，浏览器访问 `http://localhost:8933/prompt-pouch.html`（HTTP 方式才能读 prompts.json；file:// 直开会回退浏览器缓存快照，不推荐）
2. **添加提示词**：对 AI 说「把 XX 加到锦囊的写作分组」，AI 写入 prompts.json，刷新页面即见
3. **修改**：对 AI 说「修改锦囊里『日报速写』的内容」，改后刷新
4. **删除**：对 AI 说「删掉锦囊里『XX』这条」
5. **排序**：页面里拖动卡片或点 ▲▼ 调整，然后点「📋 复制排序指令」，把指令发给 AI 落盘
6. **收藏**：卡片右上角星标，收藏/取消收藏指令由 AI 同步到数据文件

## 特色功能

- **{变量} 插值**：内容含花括号占位（如「{功能名}」）的提示词，点复制会自动弹出填充面板，填入变量后实时预览再复制
- **自动备份**：点「💾 启用自动备份」授权同目录后，每次变更 2 秒内写 pouch-backup.json（滚动保留上一版 .prev.json），页内「↩ 恢复」一键回滚；浏览器不支持时对 AI 说「导出锦囊数据」生成备份文件
- **本地态**：收藏与排序存浏览器本地（IndexedDB），刷新不丢，不写数据文件

## 提醒

- 数据只在同目录 prompts.json 一个文件里，迁移/备份复制它即可
- 页面样式与脚本升级由仓库 reference.html 重新复制完成，不影响你的数据
