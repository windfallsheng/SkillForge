# 用 AI 技能包管提示词：把散落的灵光收进一只锦囊

> 关键词：提示词管理 / Agent Skills / AI 技能包 / 锦囊 prompt-pouch
> 仓库：[SkillForge](https://github.com/windfallsheng/SkillForge) · 技能简介：[SKILLS_CATALOG.md#prompt-pouch](../../SKILLS_CATALOG.md)

好提示词是资产。但大多数人的提示词过着流浪生活——散落在聊天记录、备忘录、收藏夹、转发消息里。当时灵光一闪写下的那段精妙引导，三个月后想再用，翻遍历史找不到，只能凭记忆重写，还得从头调教。

「锦囊」（prompt-pouch）就是为这件事造的 AI 技能：一个本地 HTML 管理台，把提示词按分组收纳、全文搜索、一键复制，还能给提示词留 {变量} 插值位——同一段模板，填入不同对象就能反复复用。页面与数据严格分离，双笔协作：页面可直写，AI 可代笔，你只管说，刷新即见。下面是一套十分钟上手流程。

## 第一步：安装（一分钟）

```bash
npm i -g skill-forge-hub
skill-forge init        # 交互勾选 prompt-pouch
```

也可以不从 CLI 装：直接把仓库里的 `prompt-pouch/` 目录复制进你 AI 助手的技能目录，效果相同。技能就是一份薄薄的 SKILL.md 加资源文件，与宿主无关。

## 第二步：初始化（一句话）

对 AI 说「建一个锦囊」。它会在你指定的目录生成两个东西：管理页面 `prompt-pouch.html` 和真相源 `data/prompts.json`。页面负责展示，数据负责记忆，两者严格分离——这是后面一切安全的根。首次初始化自带一份各职业通用的示例五组（写作输出/沟通协作/规划执行/复盘成长/提问艺术，每条都带 {变量} 插值），打开就有满屏样例可看；不需要样例也可以要「空锦囊」。页面内置五套主题（暖棕金/深蓝科技/IDEA 黑亮/IDEA 白亮/薄荷绿），右下角换肤坞随点随换。

还没建？也不用先建——直接对 AI 说「把 XX 存进锦囊」，它会从创建开始一路引导到入囊，全程不用你操心目录。

## 第三步：开始收藏（口述即可）

**单条入囊**：对 AI 说「把这段话加进锦囊」——比如把某次对话里验证过的那段「角色设定 + 输出格式」整段收进去。不说分组也行：AI 会按语义推荐现有分组（内容讲周报就建议归入「写作输出」并说明理由），现有分组装不下就推荐新建一个。确认后它替你写进 JSON，刷新页面即见。

**对话沉淀**：说「把上一轮对话存进锦囊」「把最近几轮对话整理进锦囊」——AI 先把对话提炼成条目清单（标题/正文），再给你看两样东西：智能打标（每条自动配 1-3 个语义标签，可改可删）与插值泛化建议（如「把『Q3 报告』换成 {报告主题}，这条就能复用于任何主题」）。条目确认后，再推荐分组方案，两段确认一次落盘；条目少（≤3 条）时两段合一，一次确认。

也可以直接在页面表单里手动录入：点「＋ 新增提示词」填表保存，授权目录后即写即存。

## 第四步：用起来

管理台该有的都有：分组侧栏（带计数徽章）、关键词搜索（命中高亮）、收藏星标、标签点击过滤、四种排序（最新添加/最近使用/使用频率/手动，拖拽可用）、{变量} 插值填充面板（点复制自动弹面板填值）、卡片「👁 详情」弹窗（全文滚动 + 创建/修改时间线）、JSON 导入导出、使用频率统计。挑提示词时看频率，就知道哪些真正好用。

**删除与回退**：页面删提示词/分组都弹页内统一确认框防误触（分组内还有条目时先移出或删）；对 AI 说「删掉锦囊里 XX」同样先确认。AI 落盘前会留 `prompts.json.bak-时间戳` 备份，删错说「回退/恢复锦囊数据」，列出备份档选档恢复（恢复前还会再备份当前版，双保险）。页面侧另有自动备份：数据一有变更 2 秒内备份到 backup/（滚动双备份），页内「↩ 恢复」一键回滚。

**换电脑迁移**：旧机「⤓ 导出」JSON 文件，新机「⤒ 导入」整库恢复（含分组与标签）；复制 data/ 与 backup/ 两个目录过去同样可行。

## 为什么做成「技能」而不是「应用」

关键差别在宿主中立。锦囊今天在 Qoder 里用，明天换 Claude Code、Cursor，复制过去同样能唤起，数据 JSON 原样带走。提示词是你的，不是某个工具的。

## 结语

提示词管理的正确姿势，不是「记住更好的提示词」，而是让每条好提示词都有一个回得来的家。锦囊的每一张卡片，都是一次被验证过的对话起点。
