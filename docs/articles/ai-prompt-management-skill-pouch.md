# 用 AI 技能包管提示词：把散落的灵光收进一只锦囊

> 关键词：提示词管理 / Agent Skills / AI 技能包 / 锦囊 prompt-pouch
> 仓库：[SkillForge](https://github.com/windfallsheng/SkillForge) · 技能简介：[SKILLS_CATALOG.md#prompt-pouch](../../SKILLS_CATALOG.md)

好提示词是资产。但大多数人的提示词过着流浪生活——散落在聊天记录、备忘录、收藏夹、转发消息里。当时灵光一闪写下的那段精妙引导，三个月后想再用，翻遍历史找不到，只能凭记忆重写，还得从头调教。

「锦囊」（prompt-pouch）就是为这件事造的 AI 技能：一个本地 HTML 管理台，把提示词按分组收纳、全文搜索、一键复制，还能给提示词留 {变量} 插值位——同一段模板，填入不同对象就能反复复用。下面是一套十分钟上手流程。

## 第一步：安装（一分钟）

```bash
npm i -g skill-forge-hub
skill-forge init        # 交互勾选 prompt-pouch
```

也可以不从 CLI 装：直接把仓库里的 `prompt-pouch/` 目录复制进你 AI 助手的技能目录，效果相同。技能就是一份薄薄的 SKILL.md 加资源文件，与宿主无关。

## 第二步：初始化（一句话）

对 AI 说「建一个锦囊」。它会在你指定的目录生成两个东西：管理页面 `prompt-pouch.html` 和真相源 `data/prompts.json`。页面负责展示，数据负责记忆，两者严格分离——这是后面一切安全的根。

## 第三步：开始收藏（口述即可）

不用打开编辑器。对 AI 说「把这段话加进锦囊」——比如把某次对话里验证过的那段「角色设定 + 输出格式」整段收进去，它替你写进 JSON；刷新页面即见。当然也可以直接在页面表单里手动录入。

## 第四步：用起来

管理台该有的都有：分组侧栏（带计数徽章）、关键词搜索（命中高亮）、收藏星标、标签点击过滤、四种排序（手动拖拽可用）、JSON 导入导出备份、使用频率统计。挑提示词时看频率，就知道哪些真正好用。

## 为什么做成「技能」而不是「应用」

关键差别在宿主中立。锦囊今天在 Qoder 里用，明天换 Claude Code、Cursor，复制过去同样能唤起，数据 JSON 原样带走。提示词是你的，不是某个工具的。

## 结语

提示词管理的正确姿势，不是「记住更好的提示词」，而是让每条好提示词都有一个回得来的家。锦囊的每一张卡片，都是一次被验证过的对话起点。
