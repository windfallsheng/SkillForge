# CHANGELOG · 谋定（mentor）

谋定个人投资罗盘技能与看板页面（mentor.html）的版本变更记录。版本戳 `mentor@N` 写在页面 `<meta name="sf-template">` 与 SKILL.md；本文件记录每个版本改了什么，每次升级时同步记一条。

## @18（2026-11-17）头部方案下拉 + 回测报告新窗口 tab
- 头部「方案」pill 改下拉：pill 内嵌原生 select（appearance:none + SVG 箭头 data URI，移动端走原生滚轮），options 与弹框方案匣同源（data/presets.json），change 即切换（applyPreset 抽取复用：PUT config.json → active 更新 → PUT presets.json → toast；失败回滚同步下拉，同名不切）
- 回测报告改新窗口 tab：点击「回测」时预开空白 tab 写「回测进行中」等待页（异步回调 window.open 易被弹窗拦截），跑完 openBacktestReport 指向报告；弹窗被拦兜底退回当前页跳转，主页面不再被带走

## @17（2026-11-17）贵金属行情区块 + 黄金 ETF 进网格
- 数据层：fetch_indices.py 接入新浪外盘接口（hf_XAU/hf_XAG/hf_GC/hf_SI），一次请求拉齐伦敦金/伦敦银/纽约金/纽约银，涨跌%由昨收自算；单标的失败只进告警不阻塞
- 页面：大盘行情卡新增「贵金属」分组（4 卡），按国际惯例涨绿跌红（与美股同款 us 反转）；标题徽章自动计入「贵金属 4」；hint 标注「仅行情参考，不参与网格」
- 网格池：华安黄金ETF（518880）以 etf 类型加入 targets，走现有 AkShare 前复权链路

## @16（2026-11-17）表格隔行斑马纹

- 部署版 serve.py /admin 管理页三张表同步加 td 级 zebra
