# 谋定使用指南

谋定是你的**个人投资罗盘**——本地单文件看板（mentor.html），只出指令、不代执行：它负责拉数据、算信号、把风控闸门和网格档位摆给你看，真实交易永远由你在券商 APP 里手动完成。

## 一句话原理

页面（纯 HTML，双击即开）负责「看」，数据（四份 JSON）负责「存」，Python 计算链负责「算」。三者分离，页面坏了永远可以重建，数据永远不丢。

## 第一次使用

1. 对助手说「**建一个谋定看板**」——助手会在你的目标目录生成 mentor.html + data/（参数与持仓）+ outputs/（信号落盘）+ assets/
2. 页面会通过本地服务打开（http://localhost:8933/mentor.html）；**不要双击 file:// 直开**——浏览器会拦截 JSON 读取，页面会横幅提醒你
3. 首次页面显示「尚未刷新」，对助手说「**刷新信号**」——助手代跑计算链（拉数→算信号→落 JSON），刷新页面即见首批信号

## 日常使用

| 你想做什么 | 怎么做 |
|:---|:---|
| 看今天的操作指令 | 打开看板，区块 1「今日操作清单」（buy 买/sell 卖/paused 暂停/observe 观察） |
| 改参数（资金/网格间距/止损线…） | 页面右下「参数配置」弹框，tab 分面板，保存即写回 config.json |
| 回填持仓 | 页面「📊 持仓回填」表单，填代码/数量/成本价，保存即写回 holdings.json |
| 加一个标的 | 参数配置弹框 → 「🎯 标的池」面板增删行，保存 |
| 更新信号 | 对助手说「刷新信号」（A 股数据 15:30 后完整，盘中刷新拿的是上一交易日快照） |
| 多套策略切换 | 参数配置弹框 → 「方案」页签：内置四套预置方案（新手稳健/均衡成长/进取积极）一键切换、另存当前参数为方案、删除方案（default 兜底不可删） |
| 换主题 | 右下角换肤坞（调色板图标），七套主题即点即换（浏览器记忆） |
| 备份数据 | 右下角「⇩ 导出备份」四份 JSON 合成一个文件下载；「⇧ 导入恢复」选文件校验后写回 |
| 问字段含义 | 对助手说「XX 字段什么意思」，助手按数据契约解释 |

## 四套预置方案怎么选

方案页签内置四套预置，切换 = 用方案整体覆盖当前参数（写前自动备份）：

| 方案 | 适合谁 / 什么行情 | 一句话画像 |
|:---|:---|:---|
| default | 内置兜底（不可删） | 中性均衡，与默认参数同源 |
| 新手稳健 | 刚入门 / 熊市防守 | 留 25% 现金、仓位上限 60%、3% 大网格少折腾、止损 8%、转债 3 只且买价 115/溢价 15 更严 |
| 均衡成长 | 有一定经验 / 震荡市 | 留 15% 现金、仓位 75%、2.5% 网格、转债 5 只（买价 120/溢价 18） |
| 进取积极 | 经验丰富 / 牛市主升 | 留 8% 现金、仓位 90%、2% 小网格高频、6 档、转债 7 只 |

切换后有两件事别忘了：① capital 是占位值 50000，改回你的实际资金；② targets 标的池是空的（default 是示例标的），填你自己的标的。改完对助手说「刷新信号」才生效。老看板说「补预置方案」即可并入这四套（你已存的方案不动）。

## 三个注意

- **file:// 陷阱**：直开页面读不到数据。页面横幅有提示，起服务即可（助手代劳）
- **信号 ≠ 建议**：谋定按你设定的规则机械计算，AI 附注在隔离区展示、永不与规则信号混排；买卖决策与执行始终由你
- **数据安全**：参数/持仓/信号都在你本机 JSON 文件里，云端无份；改配置出信号前可先在页面里反复调
- **功能边界**：本技能是本地个人版，**无登录 / 密码 / 访客功能**（数据只在本机，天然无需认证）——登录、访客通行码、防爆破锁等访问控制是云端部署版（Pyxis）的专属能力，两版代码彻底分开、互不混入

## 页面结构（8 区块）

顶部状态栏（风控/健康）→ 实时快照 → 今日操作清单 → AI 审查附注（隔离区）→ 投资组合总览 → 网格档位图 → 转债轮动候选 → 数据健康状态；侧栏为参数配置与持仓回填入口。

## 升级与备份

- 说「**升级谋定**」可把旧页面升级到新模板（数据文件一概不动）
- **自动备份**：页面写回参数/持仓、刷新信号落盘前，旧文件自动滚动存到看板目录 backup/（每文件只留最近 3 份，超出自动删旧）；backup/ 不对浏览器暴露
- **一键导出**：右下角「⇩」把四份 JSON 合成 `mentor-backup-<时间戳>.json` 下载，可发邮箱、放网盘异地保存
- **一键恢复**：右下角「⇧」选备份文件，校验通过逐份写回、页面自动刷新；导入前状态也会自动留档，可反悔
