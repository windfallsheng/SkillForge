# 行业适配（职业词典）

报告骨架（三段式/TL;DR/概览卡/热力图/柱图/风险建议环）行业无关，只有「行业变量」随职业切换。用户对话中声明职业即按词典取词（如「帮我写份销售周报」→ 销售词条）；词典没有的行业走兜底。

- 用户角色画像：顶部「默认配置」的 ROLE 定义用户默认角色与主要工作内容（当前：程序员，企业内技术开发，负责前端、后端方向）；未提职业时按 ROLE 画像取词（当前等价研发词条：git 提交聚合 + 提交/版本术语 + 提交数/活跃天数/文件数/行数指标 + 提交热力图/节奏柱图）
- 触发：话术含职业词（销售/运营/产品/HR/财务/市场/客服/项目/PMO/行政/法务/设计等）→ 标题、工作单元术语、概览指标、热力图/图表主题、风险话术全部按该词典词条生成
- 临时换角色：说「以 XX 的身份写周报」（如「以销售经理的身份写」）→ 当次按该角色词条生成，不改配置
- 永久换角色：说「以后默认用 XX 角色 / 我的职业是 XX / 我的主要工作是 XX」→ 更新顶部 ROLE 配置（永久生效）；词典没有的角色按用户描述新增词条
- 声明+临时指标覆盖：说「这次指标看拜访数和签约额」→ 词条 + 临时指标（仅当次）；说「以后都用这套指标」→ 固化进词典（永久）
- 兜底：词典外的行业（工地施工、医生值班等）→ 骨架 + 用户素材（文字/图片/文件）现场生成词条（工作单元/指标从素材提取），本次生效；说「记住这个行业」→ 固化为新词条
- 行业/角色切换只换内容与指标，HTML 骨架/色板/动效/落盘规范全部不变；纯文字整理模式同样适用词典；无 git 数据时概览卡只显示完成任务/计划/风险条数统计；优先级：临时角色声明 > 顶部 ROLE 配置 > 词典表
