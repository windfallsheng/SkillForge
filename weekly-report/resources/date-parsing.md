# 周定位解析（自然语言优先）

先解析用户话术得到目标周（周一为一周起点，结束日为顶部 WEEK_END 配置的周结束日，默认周五），再收集该周提交。解析规则：

| 说法示例 | 解析规则 |
|---|---|
| 写周报 / 生成周报（未提任何时间） | **默认本周，不追问** |
| 本周周报 / 这周周报 / 这一周的周报 | 今天所在周 |
| 上周周报 / 上上周周报 | 今天所在周 -1 / -2 周 |
| N 周前的周报 | 今天所在周 -N 周 |
| 10月第2周的周报 | 该月第 2 个周一起始的周（该月 1 日所在周计第 1 周）；缺年份默认当前年 |
| 10月20号所在周的周报 | 该日期所在周（周一至周结束日 WEEK_END）；缺年份默认当前年，若晚于今天取去年同日 |
| 20261020 所在周的周报 | 同上，日期直接给定 |
| 国庆那周 / 春节那周 / 元旦那周 / 五一那周 / 端午那周 等节假日锚定 / 国庆前那周 / 春节后那周 等 | 现场推算该节日的公历日期（农历节日按农历换算，AI 实时计算）定位所在周；今年该节日已过取今年、未到取去年（最近的过去一次）；「X节前/后 N 周」= 节日所在周 ±N 周，推算结果在标题旁注明 |
| 10月第2周到第3周的周报 / 10月20号到11月6号的周报 / 上上周到上周 | 连续多周批量生成：按周区间切片（每个周区间一份周报，周一起点、WEEK_END 结束日），两端分别按本表单点规则解析（终点缺年份沿用起点年份、终点月份早于起点月份视为下一年；终点可写「本周/上周」），按时间正序逐周生成一份周报 |

- 解析出目标周周一后，周结束日 = 周一 + N 天（friday=+4、sunday=+6、saturday=+5），写入标题与提交记录聚合的起止范围；落盘子目录名 = 周结束日日期
- 批量生成流程：先一次性收集区间内所有周的提交（逐周分片 --since/--until），再按时间正序逐周生成（本周可引用下一周数据做「下周计划」，见「输出内容与数据来源」节），最后统一落盘与截图；批量时只自动打开最后一周的 html、其余仅落盘不开浏览器，避免开多个标签页；对话中按周分隔输出各周 md 正文
- 未提及任何时间词（如"本周/上周/10月第2周"）时，一律默认本周直接生成，不追问用户
- 解析结果有歧义时以最近过去的周为默认，并在标题中注明解析出的周范围
