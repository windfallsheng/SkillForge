# 内容规则

## 输出内容与数据来源
- 四段结构：本周结论（三句判断）/ 本周任务进度（5-15 点）/ 下周计划 / 风险阻塞点
- 「本周结论」三句固定三要素，各 15-30 字：①最重要的结果（本周最值得写入的成果判断）②最值得处理的变化（节奏/质量/协作层面的关键变化）③下周最优先的动作（下周最该做的一件事）；先判断后事实、不罗列条目；与 TL;DR 呼应但不重复（TL;DR 给全周总体判断，结论三句给分项判断）
- 任务点格式：1、任务描述（量化数据）- 进度XX% - 用时X.XD（1D=8H）
- 量化数据优先级：用户口述的业务结果指标（响应时间/错误率/成功率/转化率等）优先写入；提交统计（文件数/行数/提交次数）仅在无业务指标时兜底；两者都有时业务指标在前、提交统计后置或省略
- 数字凡有对比基准必带（环比/同比/目标完成度至少其一，如「+29%」「达目标 80%」）；无基准来源时不作要求
- 任务来源（默认）：各仓库本周 提交记录自动聚合（同主题多日提交合并为一条）+ 本次会话中用户已提及/口述的工作内容 + 用户口头补充，全部合并去重；仅当用户明确说"只整理这段文字/只按这段"时才忽略提交记录与会话上下文、只用指定文字（见「纯文字整理模式」）
- 「下周计划」取材双通道：①用户口述/文字补充的计划（优先并入）；②一次生成多周周报、或后续日期日报已生成时（本次批量生成中下一周的周报，或 reports 目录中已存在的后续日报/下周周报），从下一周周报的「本周任务进度」（无下周周报时从下周各日报的任务进度）中抽取任务作为「下周计划」（抽取数量灵活、不设死上限：下周完成任务多且连续性强时可多抽至 5-6 条，少则抽 2-3 条，与下一周内容形成呼应即可），描述改写为计划语气（完成态改进行态：如「完成 XX 重构」→「推进 XX 重构」「继续 XX 开发」，去掉量化数据/进度/用时）；批量多周时优先保证跨周连续性：抽取时尽量让本周「下周计划」与下一周「本周任务进度」形成「计划→完成」的同主题承接链（如本周计划「启动 XX 重构」→ 下周完成「完成 XX 重构」，长期任务串成连续的工作链）；无后续数据时，该段按口述或「暂无」处理
- 量化数据取自 git --stat（文件数、增删行数）；用时为合理估算（提交记录不记录耗时，估算值注明"约"，可口头修正）
- 数据收集范围：按 user-config.md 的 DATA_SOURCES 清单收集（按当前系统自动选路径，另一系统的路径自动跳过）；本周无提交的仓库不写入
- HTML 版为参考图式深蓝面板卡片美化样式（实心深蓝卡片 + 细密水平条纹 + 上下边缘高光线 + 左缘节色条，保留 ask 同款发光动效）：附「本周概览」Bento 卡片（完成率圆环大卡 + 提交热力图 5天×3时段 + 提交数/活跃天数/涉及文件/代码行数四指标 + 提交节奏柱图带 hover 明细 + 环比行）、头部卡片下「本周结论」卡（三行：最重要的结果/值得处理的变化/下周优先的动作，紫色左缘色条 + 紫/橙/青三色标签，与分节卡片同质感）、顶部「一键复制」按钮（复制纯文本版）+ TL;DR 摘要行、「本周任务进度」标题右侧带周范围徽章（跟随 WEEK_END）+ 进度条终点圆点与流星扫描填充 + 液态玻璃卡片（@supports 兜底）+ CRT 扫描光带 + 全页 3D 微倾斜（±0.75°）、页脚署名 GENERATED BY SPECCORE TEAM（周范围动态跟随 WEEK_END），并随 FORMATS 默认落一张内容区截图 content-png（概览与卡片整体 + 四周留白 + 周范围徽章）

## 用户补充任务

用户调用时可能口头追加任务（如"还有一件事：这周处理了两天的支付问题"），按以下规则处理：

- **触发**：话术含"补充/加上/还有/另外/以及/对了"等追加词，或直接口述任务内容（说"整理成周报/只整理这段文字/只按这段/不要别的来源"时走「纯文字整理模式」，不是追加）
- **分段**：补充内容带分段词时按段并入——"下周计划/计划：xxx"→ 下周计划段；"风险/阻塞：xxx"→ 风险阻塞点段（说"风险暂无/无风险"→ 风险段写「暂无」）；不带分段词默认并入"本周任务进度"
- **拆条**：按语义主题拆分，一个主题一条；拆分信号：时间词（周几/上几天）、追加连接词、分号顿号列举、数字列举（1、2、3）
- **润色**：口语整理为规范任务描述（动词开头、说清对象与结果）；周报粒度较粗，多条零散小任务合并为一个周交付物条目（30-60 字）；用户未给量化数据时，优先从 提交记录补文件数/行数，无记录则省略量化、只写进度与用时（估算值注明"约"）
- **去重**：与 提交记录聚合任务合并时，同一件事只保留一条
- **格式**：与 提交记录聚合条目同格式，接在"本周任务进度"下继续编号

## 纯文字整理模式（用户贴一段文字，无 提交记录）

用户调用时直接贴一段文字并说"整理成周报/根据这段生成周报"（可能不是开发岗位，没有任何 提交记录），按以下规则处理：

- **触发**：话术含"整理/根据这段/以下内容/帮我梳理"等 + 附了一段多句文字/图片/文件，或明说"只整理这段文字/只按这段/不要别的来源/不要别的来源"（与"写周报 + 补充一下"的区别：文字/图片/文件是唯一主源、跳过提交记录与会话上下文，不是追加）
- **数据来源**：用户文字/图片/文件为主源，**跳过 提交记录收集**（不跑聚合命令）且忽略本次会话其它工作内容；图片用 Read 视觉理解提取图中文字信息，md/txt 直接读文本，docx/pdf 优先尝试 pandoc 转文本（无 pandoc 则请用户粘贴文字）；用户是开发且内容提到代码相关工作时，可仍收集提交记录用于补量化数据
- **三段归类**（用户文字没按段写明时用信号词归类）：
  - 含"下周/接下来/计划/准备/打算/将要/待办" → 下周计划
  - 含"风险/阻塞/问题/卡住/困难/待定/依赖/遗留" → 风险阻塞点
  - 其余 → 本周任务进度；全段无任何信号词 → 全部归入本周任务进度
  - 用户已明确分段（"本周完成：A；下周计划：B；风险：C"）→ 按用户分段，不猜
- **拆条**：按语义主题拆分，一个主题一条；拆分信号：时间词（周几/前几天）、连接词（还有/另外/以及）、分号顿号列举、数字列举（1、2、3）、换行/段落边界
- **润色**：口语整理为规范任务描述（动词开头、说清对象与结果）；周报粒度较粗，多条零散小任务合并为一个周交付物条目（30-60 字）
- **量化数据**：无 提交记录 → 不写文件数/行数/提交次数；格式退化为「1、任务描述 - 进度XX% - 用时X.XD」
- **进度与用时**：文字没给进度时，完成任务默认 100%、计划默认 0%；用时/预估用时仅在用户文字给出时才写，没给就省略（不瞎编估算值）
- **风险阻塞点**：素材没给影响/建议时只列描述；素材含影响/建议/责任时间时按四环结构写全
- **本周结论**：纯文字素材同样生成结论三句（素材够判断即可，不够时第②③句写「暂无」）
- **周定位/落盘/HTML**：与常规流程一致（默认本周、md/txt/html 三文件 + 内容区截图落盘、html 自动打开）；html 概览卡片无 提交数据时只显示任务进度/计划/风险条数统计

## 输出格式

```markdown
# 本周周报 - YYYYMMDD ~ YYYYMMDD

> 生成时间：YYYY-MM-DD HH:MM:SS

## 本周结论
1、最重要的结果：xxx
2、值得处理的变化：xxx
3、下周最优先的动作：xxx

## 本周任务进度
1、任务描述（量化数据：文件数/行数/提交次数）- 进度XX% - 用时X.XD

## 下周计划
1、任务描述 - 完成标准：XX（时间点）- 进度XX% - 预估用时X.XD

## 风险阻塞点
- 问题描述；影响：xxx；建议：xxx；责任与时间：xxx（谁/何时，口述有时必写）
```

## 规则

- 任务进度 5-15 点，每点 30-60 字；序号用中文顿号（1、2、）
- 聚合后任务数超上限（15 点）时，同类小任务合并压缩到上限内；用户说「精简点/太长了」→ 条目数取下限、每点压缩到 30 字左右；说「详细点」→ 条目数取上限、每点写足 60 字
- 四段兜底：任务进度默认 100%；本周结论/本周任务进度/下周计划/风险阻塞点无任何内容时该段写「暂无」（默认聚合时下周计划无 提交来源，用户没给计划就写「暂无」）
- 计划每点带进度百分比与预估用时；用户口述/文字给出完成标准时（如「周五前出唤醒效率对比」），必写「完成标准：XX（时间点）」，未给出则省略
- 风险阻塞点四环结构：问题+影响+建议+责任与时间，不写进度用时；第四环「责任与时间（谁/何时）」取自用户口述，未提供时省略
- 用时单位：X.XD（天，1D=8H），估算值注明"约"
- 文字风格约束：①下周计划用计划态陈述句，动词取「推进/启动/开展/跟进/梳理/筹备/验证/排查/联调」等计划态词，禁用完成态词（完成/搞定/已实现/做完），可带「计划/预计/拟」字样（不必每条都有），句式「动词+对象+目标范围」（如「推进底部导航重构，完成主流程交互调整」），禁祈使句（「去做 xx」）与口语（「把 xx 弄一下/搞搞」）；②完成任务用动词开头的完成态陈述句（完成/修复/优化/重构/开发/实现/接入/升级/排查/联调/上线），说清对象与结果（如「完成底部导航重构」）；③风险阻塞点四环结构：问题+影响+建议+责任与时间（问题客观陈述、影响说明后果、建议给出可执行对策、责任与时间来自口述缺省省略），不写抱怨与情绪话；④任务流水与清单条目保持无主语（动词开头）；结论、判断、归因处允许第一人称「我」（「我主导了 XX 联调」「我判断风险可控」「我推动 XX 落地」），团队协作成果用「我们」；不用口语语气词（啦/啊/吧/哈/哦/呢）、不用 emoji、不用口语形容词（差不多/还行/基本上/搞不定/一堆）；用户口述/补充的口语内容一律先润色为规范书面语再写入（「上午改了角标接口」→「完成角标接口改造」），量化数据（文件数/行数/进度/用时）格式不变
- 技术动作翻译：用户口述技术动作且带结果数据时，翻译为业务结果表述（「重写 SQL 加索引」→「查询响应 3.2s→0.4s」）；仅含动作无结果时保留动作描述，并在对话中提示可补充结果指标
- 落笔前五问自检：①第一句是不是结论？②数字有没有对比基准？③卡点有没有责任动作和时间？④计划能不能被验证？⑤个人贡献与团队成果的归属是否清晰？任一不过，改写后再输出
- 报告标题下输出生成时间，精确到时分秒（YYYY-MM-DD HH:MM:SS）
- 生成报告时，对话中先输出简要「使用提示」（几条速览 + 完整说明引用）再输出报告正文，固定条目：
  - 默认生成本周；「上周周报 / 10月第2周的周报 / 10月20号所在周的周报」指定周
  - 「补充一下：xxx」追加任务（「下周计划：/风险：」分段词自动归段）；贴文字/发图片/给文件「整理成周报」默认直接生成，说「先看看效果」→ 确认后再落盘
  - 默认多源聚合：提交记录（有仓库时）+ 本次会话已提的工作内容，没有提交记录则以口述/文字为准；说「只整理这段文字」→ 仅用该文字
  - 「写到桌面 / 不落盘 / 只要 md / 只要截图 / 这次不截图 / 别开浏览器 / 保留之前的」临时控制落盘；「这次按 xxx 模板来」临时换模板；「这周按周日收尾」临时改周结束日
  - 生成完成后在对话中告知本次落盘的文件完整路径清单（目录 + 各文件名，Windows 用反斜杠）
  - 默认配置长期生效：改 skill 文件顶部「默认配置」节（DISK/FORMATS/DIR/OPEN_HTML/TEMPLATE/WEEK_END/CONFIRM）
  - 📖 完整使用说明：问「周报怎么用」
- 默认聚合来源：提交记录（有仓库时）+ 本次会话中用户已提及/口述的工作内容全部合并去重（没有提交记录 或非代码工作以口述/文字为主）；仅当用户明确说"只整理这段文字/只按这段"时，才只用指定文字、忽略其它来源
- 纯文字整理模式：用户贴一段文字/发图片/给文件说"整理成周报/只按这段"时跳过 提交记录收集与会话上下文，内容为主源（图片 Read 视觉提取、md/txt 直接读、docx/pdf 优先 pandoc 转文本）；按信号词自动三段归类（用户已分段则按用户分段）；无量化数据不写文件数/行数，进度默认完成 100%/计划 0%，用时用户没给就省略；CONFIRM: never 默认直接生成落盘不确认，CONFIRM: text/always 或用户说"先看看效果"时先出整理效果、用户说"可以/确认/落盘"后再落盘，说"改一下 xxx"按意见修改后重新确认，说"不用确认/直接落盘"跳过确认（CONFIRM 配置控制，临时口头要求优先）
- 模板优先级：用户临时口头指定的模板 > 顶部 TEMPLATE 配置（custom 用「📝 自定义模板」节结构，default 用内置四段式：本周结论 + 三段）；自定义模板只改段名/段数/条目格式，其余规范（中文顿号序号、生成时间、落盘、HTML 样式）不变
- 目录名 = 当周最后一天（顶部 WEEK_END，默认周五）的日期，不是生成时刻：本周周报目录用本周五日期；用户可改 WEEK_END: sunday 等（则用周日日期）；周范围、标题日期范围、提交记录收集范围同步跟随 WEEK_END
- 周定位优先按自然语言解析（如"10月第2周"、"10月20号所在周"）；显式参数 `/weekly-report [YYYYMMDD] [md|txt|html]`（参数为该周任一日期）等价于自然语言，缺省为本周 + md
- 跨系统兼容：执行时先检测当前系统（macOS/Windows），所有路径、命令、浏览器均按系统分支取值（DIR auto→DIR_MAC/DIR_WIN、仓库表对应路径列、Chrome/Edge 路径、open/Start-Process、桌面/回退目录）；禁止假设单一系统
- 落盘行为读取顶部「默认配置」（DISK/FORMATS/DIR/OPEN_HTML/TEMPLATE/WEEK_END/CONFIRM）；优先级：用户临时口头要求（不落盘/写到桌面/只要 md/只要内容区截图/只要截图/这次不截图/别开浏览器/临时换模板/临时改周结束日/先看看效果/不用确认等，仅当次生效）> 顶部默认配置；DIR（按系统解析）目录/盘符不存在时回退用户主目录 reports（macOS=~/reports、Windows=%USERPROFILE%\reports）；同一周重复生成覆盖原文件，用户说"保留之前的"则时间戳另存
