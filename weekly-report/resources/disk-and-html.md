# 本地落盘（默认行为）

- 落盘根目录读取顶部「默认配置」的 `DIR`（默认 `auto`：按当前系统自动选 `DIR_MAC` / `DIR_WIN`），按当周最后一天（WEEK_END 对应的日期，默认周五）建子目录（macOS：`<DIR>/YYYY-MM-DD/`；Windows：`<DIR>\YYYY-MM-DD\`，目录不存在则自动创建）；改配置节里的 DIR / DIR_MAC / DIR_WIN 即可改变全局默认位置，改 WEEK_END 即可改变目录锚点日期
- 换机器/目录不存在回退：落盘前检测 DIR 是否存在（macOS：`test -d <DIR>`；Windows：PowerShell `Test-Path '<DIR>'` 或 node `fs.existsSync`），目录/盘符不存在时默认根目录自动改用用户主目录下 reports（macOS=`~/reports`、Windows=`%USERPROFILE%\reports`，不存在则自动创建），保证任何机器都能落盘
- 使用时用户临时指明位置（如"写到桌面"、"存到 ~/report（macOS）/ D:\report（Windows）"，覆盖 DIR、仅当次生效）：以用户指定位置为根目录，同样按当周最后一天日期子目录；"桌面"映射：macOS=`~/Desktop`、Windows=`%USERPROFILE%\Desktop`；目录不存在自动创建
- 每次生成落盘哪些文件读取顶部「默认配置」的 `FORMATS`（默认 md/txt/html/content-png 四个，md/txt/html 文件名 `weekly-report-YYYYMMDD~YYYYMMDD.<格式>`、截图文件名 `weekly-report-YYYYMMDD~YYYYMMDD-content.png`；txt 为纯文本版）；`DISK: false` 时全部不落盘
- 对话中照常输出 md 正文（不受 FORMATS 影响）；`OPEN_HTML: true` 且本次落盘了 html 时，自动打开浏览器（macOS：`open <html文件>`；Windows PowerShell：`Start-Process <html文件>`）
- FORMATS 含 content-png 时额外生成内容区截图 `weekly-report-YYYYMMDD~YYYYMMDD-content.png`：只截页面主体内容整体一张图（本周概览卡片与本周完成任务/下周计划/风险阻塞点三张卡片整体截出，不含头部标题区/复制按钮/页脚，图片四周保留对称合适的外边距约 40px 留白）：html 内置 `?shot=content` 参数（页面 JS 检测后隐藏 header-card/copy-wrap/footer、body 四周 padding 统一 40px，只留概览与三张卡片整体，正常浏览不受影响）；用 Chrome headless 访问带参 URL 截图（路径按系统选：macOS=`/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`；Windows 按序探测 `C:\Program Files\Google\Chrome\Application\chrome.exe` → `C:\Program Files (x86)\Google\Chrome\Application\chrome.exe` → `%LOCALAPPDATA%\Google\Chrome\Application\chrome.exe`，经 node child_process 执行 `--headless --disable-gpu --no-sandbox --hide-scrollbars --user-data-dir=<临时目录> --screenshot=<png路径> --window-size=760,<估算高度> --virtual-time-budget=4000 "file:///<html路径>?shot=content"`（Windows 下 URL 写作 file:///C:/...，用 node url.pathToFileURL 生成），跑完删除临时目录；禁止用 `--headless=new`（单例模式会静默失败生成占位图）；若 Chrome 不存在则换 Edge（macOS=`/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge`；Windows=`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe` → `C:\Program Files\Microsoft\Edge\Application\msedge.exe`），都找不到时跳过截图并在对话注明）；高度按内容区估算（body 上下留白~80 + 概览卡片~120 + 每节卡片(45+条目数×70+40，含各卡片 margin-bottom 18) + 余量~15，底部留白仅 body 下 padding 40px、与顶部对称，余量只防截断不可多给），截图后用 Read 校验：概览与三张卡片整体完整在图内、无头部/按钮/页脚残留、四周留白对称合适、不截断，底部留白过大则减高度、截断则加高度重截
