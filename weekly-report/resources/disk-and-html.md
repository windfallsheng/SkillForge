# 本地落盘（默认行为）

- 落盘根目录读取顶部「默认配置」的 `DIR`（默认 `auto`：按当前系统自动选 `DIR_MAC` / `DIR_WIN`），按当周最后一天（WEEK_END 对应的日期，默认周五）建子目录（macOS：`<DIR>/YYYY-MM-DD/`；Windows：`<DIR>\YYYY-MM-DD\`，目录不存在则自动创建）；改配置节里的 DIR / DIR_MAC / DIR_WIN 即可改变全局默认位置，改 WEEK_END 即可改变目录锚点日期
- 换机器/目录不存在回退：落盘前检测 DIR 是否存在（macOS：`test -d <DIR>`；Windows：PowerShell `Test-Path '<DIR>'` 或 node `fs.existsSync`），目录/盘符不存在时默认根目录自动改用用户主目录下 reports（macOS=`~/reports`、Windows=`%USERPROFILE%\reports`，不存在则自动创建），保证任何机器都能落盘
- 使用时用户临时指明位置（如"写到桌面"、"存到 ~/report（macOS）/ D:\report（Windows）"，覆盖 DIR、仅当次生效）：以用户指定位置为根目录，同样按当周最后一天日期子目录；"桌面"映射：macOS=`~/Desktop`、Windows=`%USERPROFILE%\Desktop`；目录不存在自动创建
- 每次生成落盘哪些文件读取顶部「默认配置」的 `FORMATS`（默认 md/txt/html/content-png 四个，md/txt/html 文件名 `weekly-report-YYYYMMDD~YYYYMMDD.<格式>`、截图文件名 `weekly-report-YYYYMMDD~YYYYMMDD-content.png`；txt 为纯文本版）；`DISK: false` 时全部不落盘
- 对话中照常输出 md 正文（不受 FORMATS 影响）；`OPEN_HTML: true` 且本次落盘了 html 时，自动打开浏览器（macOS：`open <html文件>`；Windows PowerShell：`Start-Process <html文件>`）
