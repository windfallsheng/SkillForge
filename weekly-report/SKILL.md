# 周报生成

聚合各仓库 git 提交 + 本次会话口述内容生成三段式周报（本周完成任务/下周计划/风险阻塞点 + 本周概览卡），对话输出 md 正文 + 落盘 md/txt/html/content-png 并自动打开 html。

## 生成流程

1. **解析周**（自然语言 → 目标周：周一起点、WEEK_END 结束日）→ 读 `resources/date-parsing.md`
2. **收集数据**（本周 git + 会话口述 + 口头补充，合并去重；同取上周数据供概览环比）→ 读 `resources/data-collection.md`
3. **内容归类与润色**（聚合来源 / 补充任务 / 纯文字模式 / 输出格式 / 写作风格）→ 读 `resources/content-rules.md`
4. **行业词条**（话术含职业词时按词典取词）→ 读 `resources/industry-dictionary.md`
5. **落盘与截图**（md/txt/html/content-png + 自动打开 html）→ 读 `resources/disk-and-html.md`
6. **使用咨询**（用户只问「周报怎么用」等用法、未要求生成）→ 读 `resources/usage-guide.md`，将其内容原样输出（首行标题改为「周报生成器使用指南」），不收集 git、不生成报告、不落盘、不开浏览器

## ⚙️ 默认配置（用户可手动修改；临时口头要求永远优先）

```yaml
DISK: true                     # 是否落盘写文件；false = 默认只在对话输出，不写文件不开浏览器
FORMATS: [md, txt, html, content-png] # 落盘哪些格式（数组，可删减/增，如 [md, html] / [md, txt, html]（不截图）；content-png = 内容区截图（仅本周概览卡片与本周完成任务/下周计划/风险阻塞点卡片，不含头部标题/复制按钮/页脚），删除该项即不截图；不影响对话中的 md 正文输出）
DIR: auto                      # 落盘根目录：auto = 按当前系统自动选 DIR_MAC / DIR_WIN（也可直接写死某个绝对路径）
DIR_MAC: /Users/luzhaosheng/MyWork/智慧食堂/reports    # macOS 落盘根目录（日报按目标日期、周报按当周最后一天建子目录；目录不存在时回退用户主目录下 reports）
DIR_WIN: d:\Workspace_QCoder\reports                   # Windows 落盘根目录（日报按目标日期、周报按当周最后一天建子目录；目录/盘符不存在时回退用户主目录下 reports）
OPEN_HTML: true                # 落盘后是否自动用浏览器打开 html（FORMATS 不含 html 时忽略）
TEMPLATE: default              # 报告模板：default = 内置三段式（本周完成任务/下周计划/风险阻塞点）；custom = 使用下方「📝 自定义模板」节；口头临时指定模板仅当次生效
ROLE: 全栈开发工程师（企业内技术开发）  # 用户默认职业角色与主要工作内容（两者并存：职业名 + 括号内工作内容，生成内容/术语/量化指标/热力图/柱图/风险话术全部按此画像走）；用户随口描述职业时（如「我搞装修的，天天跑工地」）→ AI 提炼为规范表述（装修项目经理（负责工地现场管理、施工进度与质量巡检））更新此处；说「以 XX 的身份写」→ 当次临时换角色不改配置；说「以后默认用 XX 角色 / 我的职业是 XX / 我的主要工作是 XX」→ 永久更新此处
WEEK_END: friday               # 周结束日（当周最后一天）：friday = 每周五（默认）；可改 sunday = 每周日、saturday 等；周范围、落盘子目录名均按该天日期
CONFIRM: never                 # 落盘前确认：never = 直接生成落盘不确认（默认）；text = 纯文字整理模式先出效果确认后再落盘；always = 任何方式生成都先确认；临时说「先看看效果」当次先确认、说「不用确认」当次跳过
```

> 临时口头要求（仅对当次生效，不修改上方配置）：说「不落盘/别写文件」→ 当次 DISK=false；说「写到桌面/存到 ~/report（macOS）或 D:\report（Windows）」→ 当次改用该 DIR；说「只要 md / 只出 html / 只要内容区截图」→ 当次只落指定格式；说「这次不截图」→ 当次不生成内容区截图；说「只要截图/重新截个图」→ 当次只对现有 html 执行内容区截图（不重新收集 git、不重写 md/txt/html 内容文件）；说「别开浏览器」→ 当次 OPEN_HTML=false；说「这周按周日收尾/这周算到周日」→ 当次 WEEK_END=sunday（当次周范围与目录名跟随）；说「这次按 xxx 模板来」→ 当次临时换模板（不改配置）；说「以后都用这个模板」→ 自动写入下方「📝 自定义模板」节并把 TEMPLATE 改为 custom（永久生效）；说「先看看效果/先出效果再落盘」→ 当次先出效果确认后再落盘；说「不用确认/直接落盘」→ 当次跳过确认直接落盘。

## 📝 自定义模板（TEMPLATE: custom 时启用，用户可手改，适配各类岗位）

把顶部 TEMPLATE 改为 custom 后，按下面结构生成报告（段名、段数、条目格式均可改）：

```text
段一：本周工作内容（每条：工作描述 - 完成情况）
段二：存在问题与困难（只列描述）
段三：下周工作计划（每条：计划描述 - 预计完成时间）
```

> 只写段结构与条目格式即可；未写明的细节（中文顿号序号、生成时间行、落盘行为、HTML 样式）沿用默认规范。

## 规则速览

- 完成任务 5-15 点、每点 30-60 字；序号用中文顿号（1、2、3）
- 三段兜底写「暂无」；计划点带进度百分比与预估用时；风险阻塞点三环（问题+影响+建议）
- 用时单位 X.XD（天，1D=8H），估算值注明「约」；落盘子目录名 = 当周最后一天（WEEK_END）日期
- 完整规则（聚合来源 / 纯文字模式 / 写作风格约束 / 使用提示）见 `resources/content-rules.md`
