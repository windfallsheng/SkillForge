# 落盘索引与检索（阶段 2-3）

## 落盘结构

```
{DIR}/
├── INDEX.md                    # 总索引：按主题分组，时间倒序
└── decisions/
    └── {主题slug}/
        └── YYYY-MM-DD-{内容slug}.md
```

- 落盘前按 ASK_CONFIRM 决定是否先展示内容等确认；写前重读当日文件避免覆盖
- **落盘完成后对话报告落盘位置**：完整路径 + INDEX.md 是否已更新
- INDEX.md 每条一行摘要：`- {日期}｜{决策一句话} → [文件](decisions/{主题slug}/{文件名}.md)`

## 检索（用户说「查决策」）

1. grep INDEX.md 命中关键词 → 输出命中条目摘要清单（日期 + 一句话结论 + 主题）
2. 用户指定条目 → Read 对应文件全文，输出四元组
3. 命中为空 → 如实报告「日志中没有相关决策」，并提示可按主题记录一条
