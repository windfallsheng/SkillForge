# 记录（阶段 1）

## 四元组模板

```markdown
# {日期} {主题}：{决策一句话}

- **结论**：{做了什么决定，一句话}
- **取舍权衡**：{选它的理由 / 代价与收益 1-3 条}
- **被否方案**：{考虑过但否掉的方案 + 否决理由}
- **适用与失效**：{什么条件下成立；什么条件出现时要重新审视}
```

## 记录纪律

- 四元组缺一不可；用户口述缺项时逐项追问补齐（一句话可答），不编造
- 结论用肯定句写「做了什么」，不写「考虑中」之类的模糊态
- 主题归类：用户说了主题就用；没说按内容提取稳定主题词（如「数据层」「发布流程」），slug 用英文短横线（data-layer），中文名保留在标题与索引
- 文件名：`YYYY-MM-DD-{内容slug}.md`（同一天同主题追加到当日文件新条目）
