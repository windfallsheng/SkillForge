# 决策日志使用指南

## 能做什么

把重要决策沉淀为四元组日志（结论 / 取舍权衡 / 被否方案 / 适用与失效条件），按主题聚合、时间倒序索引，随时一句话检索复盘。

## 怎么用

1. 说「**记一条决策**」+ 口述内容（如「决定数据层用内嵌 ID 命名空间而不是固定键」）
2. 我按四元组补全缺项（被否方案 / 失效条件等逐项追问），落盘到 `decisions/{主题}/`
3. 说「**查决策** 数据层」→ 输出命中摘要清单，点条目看四元组全文
4. 季度 / 年度复盘时：「把今年决策聚合一下」→ 按主题汇总输出

## 可改配置（user-config.md）

- `DIR`：日志根目录（默认当前项目 .decisions/）
- `TEMPLATE`：记录模板（four-tuple 四元组）
- `ASK_CONFIRM`：落盘前是否先确认

## 使用提示

- 四元组缺一不可，口述缺项我会追问补齐
- 追加不覆盖，同主题决策按时间沉淀，复盘时脉络完整
