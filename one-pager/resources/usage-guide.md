# 一页纸海报使用指南

## 能做什么

把一个主题或一句话想法变成一页纸 HTML 海报：大标题 + 金句 + 要点块（3-5 条）+ 页脚，纵向一屏排版、打印友好，可顺带截出 PNG 图片，适合分享、发群、贴文档。内置 **8 套布局模板 × 10 套配色主题 = 80 种版式**，页面右下角两个切换坞随手换，换完自动记住。

## 怎么用

1. 说「**做张海报**」+ 主题（如「做一张『AI 改变工作』的海报」）
2. 我提炼草稿（标题/金句/要点）→ 你确认或改口 → 生成
3. 产出：`posters/<主题>/` 目录内三件套——`poster.html` + `poster.md` 底稿 + `poster.png` 截图（SHOT 开启时），自动打开浏览器，落盘后报路径

## 页面内切换（生成后随时可换）

- **模板坞**（右下角上方，八个标签）：经典 / 极简 / 杂志 / 巨幕 / 时间线 / 栅格 / 数据 / 粗野，八套布局骨架随点随换
- **主题坞**（右下角下方，十色点两行）：深蓝科技 / 浅色商务 / IDEA 黑亮 / IDEA 白亮 / 温暖渐变 / 水墨国风 / 翡翠绿 / 玫瑰金 / 午夜金 / 霓虹紫，随点随换
- 模板与主题可任意组合（如「杂志 + 温暖渐变」），选择会记忆，下次打开同一份海报仍是上次的样式

## 可改配置（user-config.md）

- `TEMPLATE`：默认布局模板（classic 经典舞台 / minimal 极简留白 / magazine 杂志社论 / hero 巨幕大字 / timeline 时间叙事 / grid 卡片栅格 / dashboard 数据仪表 / brutalist 新粗野）
- `THEME`：默认主题（tech 深蓝科技 / biz 浅色商务 / mono IDEA 黑亮 / light IDEA 白亮 / warm 温暖渐变 / ink 水墨国风 / jade 翡翠绿 / rose 玫瑰金 / midnight 午夜金 / violet 霓虹紫）
- `ASPECT`：截图纵横比（3:4 竖版 / 1:1 方版 / 16:9 横版）
- `SHOT`：是否顺带截 PNG
- `DIR`：海报库根目录（默认 posters/，可写绝对路径）；每张海报一个 slug 子目录，三件套成组互不混杂

## 使用提示

- 海报页面无滚动条、一屏展示，长内容会自动缩放
- 打印即所得：Ctrl/Cmd+P 可直接打印成纸质海报
- 换模板不会丢内容：同一份数据在八套布局间流转，挑最喜欢的那版截图分享即可
