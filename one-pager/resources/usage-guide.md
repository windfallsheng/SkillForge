# 一页纸海报使用指南

## 能做什么

把一个主题或一句话想法变成一页纸 HTML 海报：大标题渐变字 + 金句 + 要点块（3-5 条）+ 页脚，纵向一屏排版、打印友好，可顺带截出 PNG 图片，适合分享、发群、贴文档。

## 怎么用

1. 说「**做张海报**」+ 主题（如「做一张『AI 改变工作』的海报」）
2. 我提炼草稿（标题/金句/要点）→ 你确认或改口 → 生成
3. 产出：`posters/poster-<主题>.html` + `.md` 底稿 + `.png` 截图（SHOT 开启时），自动打开浏览器，落盘后报路径

## 可改配置（user-config.md）

- `THEME`：deepblue 深蓝 / gold 暖金 / mint 薄荷
- `ASPECT`：截图纵横比（3:4 竖版 / 1:1 方版 / 16:9 横版）
- `SHOT`：是否顺带截 PNG
- `DIR`：落盘目录（默认 posters/）

## 使用提示

- 海报页面无滚动条、一屏展示，长内容会自动缩放
- 打印即所得：Ctrl/Cmd+P 可直接打印成纸质海报
