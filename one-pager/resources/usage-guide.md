# 一页纸海报使用指南

## 能做什么

把一个主题或一句话想法变成一页纸 HTML 海报：大标题 + 金句 + 要点块（3-5 条）+ 页脚，纵向一屏排版、打印友好，可顺带截出 PNG 图片，适合分享、发群、贴文档。内置 **16 套布局模板 × 21 套配色主题 = 336 种版式**（含瑞士/包豪斯/蒙德里安等设计史经典版式与莫兰迪/装饰艺术/波普等业内专业配色），页面右下角两个切换坞随手换，换完自动记住。

## 怎么用

1. 说「**做张海报**」+ 主题（如「做一张『AI 改变工作』的海报」）
2. 我提炼草稿（标题/金句/要点）→ 你确认或改口 → 生成
3. 产出：`posters/<主题>/` 目录内三件套——`poster.html` + `poster.md` 底稿 + `poster.png` 截图（SHOT 开启时），自动打开浏览器，落盘后报路径

## 页面内切换（生成后随时可换）

- **模板坞**（右下角上方，十六个标签自动换行分组）：经典 / 极简 / 杂志 / 巨幕 / 时间线 / 栅格 / 数据 / 粗野 / 瑞士 / 包豪斯 / 蒙德里安 / 编辑刊 / 大字报 / 孟菲斯 / 展览 / 视窗，十六套布局骨架随点随换；若你放了用户模板，还会出现「我的模板」分组
- **主题坞**（右下角下方，二十一色点 7×3）：深蓝科技 / 浅色商务 / IDEA 黑亮 / IDEA 白亮 / 温暖渐变 / 水墨国风 / 翡翠绿 / 玫瑰金 / 午夜金 / 霓虹紫 / 瑞士红黑 / 包豪斯三原色 / 孟菲斯撞色 / 莫兰迪 / 北欧 / 装饰艺术 / 黑白电影 / 经典蓝 / 波普 / 复古胶片 / 珊瑚橙，随点随换
- 模板与主题可任意组合（如「杂志 + 温暖渐变」），选择会记忆，下次打开同一份海报仍是上次的样式

## 可改配置（user-config.md）

- `TEMPLATE`：默认布局模板（classic 经典舞台 / minimal 极简留白 / magazine 杂志社论 / hero 巨幕大字 / timeline 时间叙事 / grid 卡片栅格 / dashboard 数据仪表 / brutalist 新粗野 / swiss 瑞士国际 / bauhaus 包豪斯 / mondrian 蒙德里安 / editorial 编辑刊 / typo 大字报 / memphis 孟菲斯 / exhibit 展览 / window 视窗）
- `THEME`：默认主题（tech 深蓝科技 / biz 浅色商务 / mono IDEA 黑亮 / light IDEA 白亮 / warm 温暖渐变 / ink 水墨国风 / jade 翡翠绿 / rose 玫瑰金 / midnight 午夜金 / violet 霓虹紫 / swiss 瑞士红黑 / bauhaus 包豪斯三原色 / memphis 孟菲斯撞色 / morandi 莫兰迪 / nordic 北欧 / artdeco 装饰艺术 / noir 黑白电影 / classicblue 经典蓝 / pop 波普 / retro 复古胶片 / coral 珊瑚橙）
- `ASPECT`：截图纵横比（3:4 竖版 / 1:1 方版 / 16:9 横版）
- `SHOT`：是否顺带截 PNG
- `TPL_DIR`：你的专属模板库目录（默认 ~/.skillforge/user-templates）；把你的模板文件放进去，以后生成海报时模板坞自动出现「我的模板」分组
- `DIR`：海报库根目录（默认 posters/，可写绝对路径）；每张海报一个 slug 子目录，三件套成组互不混杂

## 用户模板库（DIY 专属模板）

1. 把 `resources/user-template-example.html` 复制到 TPL_DIR 目录，改名后照三段式注释改（META 元信息 / CSS 样式 / FN 渲染函数），颜色一律用主题令牌，21 套主题都能套
2. 下次生成海报时自动内嵌，模板坞「我的模板」分组随点随换，和官方模板一样会被记住

## 使用提示

- 海报页面无滚动条、一屏展示，长内容会自动缩放
- 打印即所得：Ctrl/Cmd+P 可直接打印成纸质海报
- 换模板不会丢内容：同一份数据在十六套布局间流转，挑最喜欢的那版截图分享即可
