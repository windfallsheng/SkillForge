# 一页纸海报使用指南

## 能做什么

把一个主题或一句话想法变成一页纸 HTML 海报：大标题 + 金句 + 要点块（3-5 条）+ 页脚，纵向一屏排版、打印友好，可顺带截出 PNG 图片，适合分享、发群、贴文档。内置 **32 套布局模板 × 25 套配色主题 = 800 种版式**（七组流派分类：现代主义/编辑出版/数据商务/艺术流派/国风雅韵/先锋实验/场景专用，含瑞士/包豪斯/蒙德里安/波普/欧普/新艺术/水墨/红金宫廷/青绿山水/酸性/故障/蒸汽波/赛博等设计史与先锋版式，配色含莫兰迪/装饰艺术/波普/酸性荧光/赛博霓虹等业内专业主题），页面顶部模板坞 + 右下角主题坞随手换，两坞默认折叠成小胶囊不遮正文，点开选完自动收起，换完自动记住。

## 怎么用

1. 说「**做张海报**」+ 主题（如「做一张『AI 改变工作』的海报」）
2. 我提炼草稿（标题/金句/要点）→ 你确认或改口 → 生成
3. 产出：`posters/<主题>/` 目录内三件套——`poster.html` + `poster.md` 底稿 + `poster.png` 截图（SHOT 开启时），自动打开浏览器，落盘后报路径

## 页面内切换（生成后随时可换）

- **模板坞**（页面顶部，默认折叠成「模板 · 当前模板」小胶囊，点一下展开）：三十二标签按七组流派分组——现代主义（经典 / 极简 / 瑞士 / 视窗）· 编辑出版（杂志 / 编辑刊 / 大字报 / 报纸）· 数据商务（数据 / 栅格 / 时间线 / 巨幕）· 艺术流派（包豪斯 / 蒙德里安 / 孟菲斯 / 展览 / 波普 / 欧普 / 新艺术）· 国风雅韵（水墨 / 宫廷 / 青绿）· 先锋实验（粗野 / 酸性 / 故障 / 蒸汽波 / 赛博）· 场景专用（学术 / 招聘 / 邀请 / 通知 / 水印），三十二套布局骨架随点随换，选完自动收起；若你放了用户模板，还会出现「我的模板」分组
- **主题坞**（右下角，默认折叠成「色点 · 主题名」小胶囊，点一下展开）：二十五色点 5×5（色点放大，hover 悬浮弹出主题名）——深蓝科技 / 浅色商务 / IDEA 黑亮 / IDEA 白亮 / 温暖渐变 / 水墨国风 / 翡翠绿 / 玫瑰金 / 午夜金 / 霓虹紫 / 瑞士红黑 / 包豪斯三原色 / 孟菲斯撞色 / 莫兰迪 / 北欧 / 装饰艺术 / 黑白电影 / 经典蓝 / 波普 / 复古胶片 / 珊瑚橙 / 酸性荧光 / 赛博霓虹 / 奶油纸 / 学术蓝，随点随换，选完自动收起
- 模板与主题可任意组合（如「杂志 + 温暖渐变」），选择会记忆，下次打开同一份海报仍是上次的样式；两坞折叠后只剩右上、右下两枚小胶囊，正文一览无余

## 可改配置（user-config.md）

- `TEMPLATE`：默认布局模板（classic 经典舞台 / minimal 极简留白 / swiss 瑞士国际 / window 视窗 / magazine 杂志社论 / editorial 编辑刊 / typo 大字报 / newspaper 报纸新闻 / dashboard 数据仪表 / grid 卡片栅格 / timeline 时间叙事 / hero 巨幕大字 / bauhaus 包豪斯 / mondrian 蒙德里安 / memphis 孟菲斯 / exhibit 展览 / popart 波普艺术 / opart 欧普艺术 / artnouveau 新艺术 / brutalist 新粗野 / acid 酸性设计 / glitch 故障艺术 / vaporwave 蒸汽波 / cyber 赛博霓虹 / academic 学术会议 / recruit 招聘 / invitation 邀请函 / notice 通知公告 / inkwash 水墨 / palace 红金宫廷 / landscape 青绿山水 / watermark 水印公文）
- `THEME`：默认主题（tech 深蓝科技 / biz 浅色商务 / mono IDEA 黑亮 / light IDEA 白亮 / warm 温暖渐变 / ink 水墨国风 / jade 翡翠绿 / rose 玫瑰金 / midnight 午夜金 / violet 霓虹紫 / swiss 瑞士红黑 / bauhaus 包豪斯三原色 / memphis 孟菲斯撞色 / morandi 莫兰迪 / nordic 北欧 / artdeco 装饰艺术 / noir 黑白电影 / classicblue 经典蓝 / pop 波普 / retro 复古胶片 / coral 珊瑚橙 / acid 酸性荧光 / cyber 赛博霓虹 / cream 奶油纸 / academic 学术蓝）
- `ASPECT`：截图纵横比（3:4 竖版 / 1:1 方版 / 16:9 横版）
- `SHOT`：是否顺带截 PNG
- `TPL_DIR`：你的专属模板库目录，默认与海报库根目录平级（如 `posters/` 旁的 `user-templates/`），所有海报产物共用；也可写绝对路径自定义；把你的模板文件放进去，以后生成海报时模板坞自动出现「我的模板」分组
- `DIR`：海报库根目录（默认 posters/，可写绝对路径）；每张海报一个 slug 子目录，三件套成组互不混杂

## 用户模板库（DIY 专属模板）

1. 把 `resources/user-template-example.html` 复制到 TPL_DIR 目录，改名后照三段式注释改（META 元信息 / CSS 样式 / FN 渲染函数），颜色一律用主题令牌，25 套主题都能套
2. 下次生成海报时自动内嵌，模板坞「我的模板」分组随点随换，和官方模板一样会被记住

## 使用提示

- 海报页面无滚动条、一屏展示，长内容会自动缩放
- 打印即所得：Ctrl/Cmd+P 可直接打印成纸质海报
- 换模板不会丢内容：同一份数据在三十二套布局间流转，挑最喜欢的那版截图分享即可
