# 海报 HTML 版式（一屏 · 8 模板 × 10 主题 · 双切换坞）

## 版式总览

- 一屏海报：`.stage` 容器满视口（100svh）内渲染当前模板，内容多时自动缩放字号（JS 按内容高度收缩，禁止滚动出第二屏）；页面 body 不产生滚动条（overflow hidden）
- **模板管布局、主题管配色，正交组合 80 种版式**：`html[data-template]` 决定渲染哪套布局骨架（八选一），`html[data-theme]` 决定配色变量（五选一）；模板只描述结构与类名，颜色一律走主题令牌
- 十主题：tech 深蓝科技（默认）/ biz 浅色商务 / mono IDEA 黑亮 / light IDEA 白亮 / warm 温暖渐变 / ink 水墨国风 / jade 翡翠绿 / rose 玫瑰金 / midnight 午夜金 / violet 霓虹紫，色值与 daily-report 同一套 12 核心契约；右下角主题坞十色点两行（5×2 网格）随点随换
- 八模板（右下角模板坞八标签随点随换）：
  1. **classic 经典舞台**：徽章 + 渐变巨字 + 装饰分隔线 + 金句 + 三列要点卡（圆点渐变球）
  2. **minimal 极简留白**：瑞士平面风，左上小标 + 衬线巨字（Georgia/'Songti SC'）+ 细线 + 编号竖排要点 + 底栏 meta
  3. **magazine 杂志社论**：刊头通栏线（masthead + ISSUE 01）+ 左标题金句右要点分栏 + 金句首字下沉 + 底栏
  4. **hero 巨幕大字**：电影海报式巨型关键词（up to 140px 渐变大字）+ 金句 + 底部要点横条三列 + 绝对定位页脚
  5. **timeline 时间叙事**：中央竖线（渐变）+ 节点圆点 + 要点卡片左右交替
  6. **grid 卡片栅格**：标题区（左标题右金句）+ 2×2 大圆角卡片（描边编号角标 + 渐变顶条，第 5 条卡片横跨整行）
  7. **dashboard 数据仪表**：左 KPI 环形图（conic-gradient，百分比随 DATA.kpi）+ 要点进度条，右标题金句 + 编号补充要点
  8. **brutalist 新粗野**：撞色块（标题反色底）+ 4px 粗框 + 8px 硬阴影 + 零圆角 + 要点横排色块
- 模板/主题记忆：localStorage 键 `poster:<ID>-tpl` / `poster:<ID>-theme`，ID = 页内嵌 poster-id meta，多份产物互不串台、改名/移动目录记忆不丢；旧版三主题值不在十主题列表，启动时自动回落 tech；模板值非法自动回落 classic
- 科技感背景层四件套（与日报/周报同款）：SVG 微噪点（opacity .04，mono 退隐）+ 60px 网格底纹 + 星点（biz/light/warm 退隐 .28、mono 灰白化）+ 全屏扫描线与循环光带
- 字体全用系统本地字体栈（system-ui + Georgia/'Songti SC'/'SimSun' 衬线（minimal/magazine 标题用）+ ui-monospace/'SF Mono'/Menlo/Consolas（编号用），品牌字体 PingFang/YaHei/apple-system 零出现），禁止 CDN、@import、外链 CSS/JS/图片/网络字体——页面离线双击可开
- 多文件隔离（必植）：头部写 `<meta name="poster-id" content="<UUID>">`（crypto.randomUUID() 标准 UUID v4）；localStorage 键一律 `poster:<ID>-xxx`，禁止裸通用键名；页面 JS 启动时校验 id meta——非法或缺失（占位残留/手写变体/误沿用旧值）时按路径键（`'sf-heal:' + location.pathname`）自愈为 crypto.randomUUID() 标准 v4 并回写 meta，console.warn 显性报警；路径键持久化保证同文件跨打开稳定复用；合法 UUID 原样放行
- 版本戳：`<meta name="sf-template" content="one-pager@4">`（模板升级递增 @N）
- 入场动画：各模板元素带 `.anim` 错峰上浮淡入（JS 按序设 animation-delay）；fill-mode 必须用 both（backwards 会在动画结束后闪回隐藏态）；2s 兜底 setTimeout 强制全显（headless 截图 / 打印预览环境内容不得永久隐藏）
- ?shot 截图模式：页面 JS 检测 location.search 含 shot 时给 html 挂 data-shot 属性（CSS 关闭入场动画直接终态，headless 虚拟时间下动画帧不推进会停在初始帧导致截图空白）、强制全部内容 opacity 1、隐藏模板坞与主题坞，输出纯海报画面
- 页脚署名固定 GENERATED BY AI TEAM（禁止真实团队名/项目名）

## 内容规则

- 要点块 3-5 条：每条 15-30 字，动词开头；超过 5 条合并取舍，不足 3 条向用户再要
- 金句 12-30 字；标题 6-14 字；超长自动截断提示用户改短
- dashboard 模板的 `kpi` 字段写百分比数值字符串（如 "82%"，控制环形图填充与中心数值）；非 dashboard 模板该字段可留默认
