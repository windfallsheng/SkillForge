# 海报 HTML 版式（一屏 · 16 模板 × 21 主题 · 双切换坞）

## 版式总览

- 一屏海报：`.stage` 容器满视口（100svh）内渲染当前模板，内容多时自动缩放字号（JS 按内容高度收缩，禁止滚动出第二屏）；页面 body 不产生滚动条（overflow hidden）
- **模板管布局、主题管配色，正交组合 700 种版式**：`html[data-template]` 决定渲染哪套布局骨架（二十八选一），`html[data-theme]` 决定配色变量（二十五选一）；模板只描述结构与类名，颜色一律走主题令牌（先锋实验组风格本体色除外：glitch RGB 错位影、acid 液态金属 blob、vaporwave 透视地平线用固定色相，不影响十三令牌其余部分）
- 二十五主题：tech 深蓝科技（默认）/ biz 浅色商务 / mono IDEA 黑亮 / light IDEA 白亮 / warm 温暖渐变 / ink 水墨国风 / jade 翡翠绿 / rose 玫瑰金 / midnight 午夜金 / violet 霓虹紫 / swiss 瑞士红黑 / bauhaus 包豪斯三原色 / memphis 孟菲斯撞色 / morandi 莫兰迪 / nordic 北欧 / artdeco 装饰艺术 / noir 黑白电影 / classicblue 经典蓝 / pop 波普 / retro 复古胶片 / coral 珊瑚橙 / acid 酸性荧光 / cyber 赛博霓虹 / cream 奶油纸 / academic 学术蓝；色值走 13 核心契约变量（--bg/--bg2/--panel/--panel-solid/--text/--muted/--accent/--accent2/--border/--glow/--glow-soft/--title-grad/--tag-bg）；右下角主题坞二十五色点（5×5 网格）随点随换
- 二十八模板六组流派（顶部模板坞二十八标签随点随换，分组标：现代主义/编辑出版/数据商务/艺术流派/先锋实验/场景专用）：
  1. **classic 经典舞台**：徽章 + 渐变巨字 + 装饰分隔线 + 金句 + 三列要点卡（圆点渐变球）
  2. **minimal 极简留白**：瑞士平面风，左上小标 + 衬线巨字（Georgia/'Songti SC'）+ 细线 + 编号竖排要点 + 底栏 meta
  3. **magazine 杂志社论**：刊头通栏线（masthead + ISSUE 01）+ 左标题金句右要点分栏 + 金句首字下沉 + 底栏
  4. **hero 巨幕大字**：电影海报式巨型关键词（up to 140px 渐变大字）+ 金句 + 底部要点横条三列 + 绝对定位页脚
  5. **timeline 时间叙事**：中央竖线（渐变）+ 节点圆点 + 要点卡片左右交替
  6. **grid 卡片栅格**：标题区（左标题右金句）+ 2×2 大圆角卡片（描边编号角标 + 渐变顶条，第 5 条卡片横跨整行）
  7. **dashboard 数据仪表**：左 KPI 环形图（conic-gradient，百分比随 DATA.kpi）+ 要点进度条，右标题金句 + 编号补充要点
  8. **brutalist 新粗野**：撞色块（标题反色底）+ 4px 粗框 + 8px 硬阴影 + 零圆角 + 要点横排色块
  9. **swiss 瑞士国际**：红黑极简 + 巨型无衬线标题 + 通栏细线 + 网格对齐
  10. **bauhaus 包豪斯**：圆/方/三角几何元素 + 三原色 + 编号要点
  11. **mondrian 蒙德里安**：8px 黑粗线网格 + 左主区/右侧色块/底部横条 + 红黄蓝色块填充
  12. **editorial 编辑刊**：刊头通栏双线 + 首字下沉衬线标题 + 左右双栏 + 双线底栏
  13. **typo 大字报**：巨型标题（clamp 60-128px）撑满 + 底部要点三列 + 顶底页脚
  14. **memphis 孟菲斯**：波点底纹 + 撞色徽章 + 卡片微斜错落
  15. **exhibit 展览**：竖排展签标签 + 斜体年份 + 展签卡片（3px 粗框 + 10px 硬影微斜）

  17. **newspaper 报纸新闻**：报头 mast 双线 + 通栏 headline + 双栏正文（column-rule 分隔）+ 首字下沉

  22. **glitch 故障艺术**：标题 RGB 错位影（#f0f/#0ff clip-path 分层）+ 要点阶梯裁切（clip-path polygon）
  23. **vaporwave 蒸汽波**：落日渐变（粉紫地平线）+ 透视网格（perspective rotateX 58deg）
  24. **cyber 赛博霓虹**：切角框（clip-path 八边形）+ 霓虹辉光（text-shadow 辉光）
  25. **academic 学术会议**：会议横幅 + 三栏摘要（ABSTRACT/KEY FINDINGS/CONCLUSION）+ 虚线图表位
  26. **recruit 招聘**：岗位巨字 + 职位标签 chips + 投递 CTA 按钮
  27. **invitation 邀请函**：烫金双线框（border + outline offset 6px）+ 居中排印

- 模板/主题记忆：localStorage 键 `poster:<ID>-tpl` / `poster:<ID>-theme`，ID = 页内嵌 poster-id meta，多份产物互不串台、改名/移动目录记忆不丢；旧版主题值不在二十五主题列表，启动时自动回落 tech；模板值非法自动回落 classic
- 设计专属清爽底：无噪点/网格/星点/扫描线氛围层（设计产物靠版式与配色本身说话），body 背景只有纯色→细腻线性渐变 `linear-gradient(180deg,var(--bg) 12%,var(--bg2) 135%)`；模板内允许自带的装饰性纹理（如 memphis 波点、swiss 色块）不算氛围层
- 字体全用系统本地字体栈（system-ui + Georgia/'Songti SC'/'SimSun' 衬线（minimal/magazine/editorial 标题用）+ ui-monospace/'SF Mono'/Menlo/Consolas（编号用），品牌字体 PingFang/YaHei/apple-system 零出现），禁止 CDN、@import、外链 CSS/JS/图片/网络字体——页面离线双击可开
- 多文件隔离（必植）：头部写 `<meta name="poster-id" content="<UUID>">`（crypto.randomUUID() 标准 UUID v4）；localStorage 键一律 `poster:<ID>-xxx`，禁止裸通用键名；页面 JS 启动时校验 id meta——非法或缺失（占位残留/手写变体/误沿用旧值）时按路径键（`'sf-heal:' + location.pathname`）自愈为 crypto.randomUUID() 标准 v4 并回写 meta，console.warn 显性报警；路径键持久化保证同文件跨打开稳定复用；合法 UUID 原样放行
- 版本戳：`<meta name="sf-template" content="one-pager@8">`（模板升级递增 @N）
- 入场动画：各模板元素带 `.anim` 错峰上浮淡入（JS 按序设 animation-delay）；fill-mode 必须用 both（backwards 会在动画结束后闪回隐藏态）；2s 兜底 setTimeout 强制全显（headless 截图 / 打印预览环境内容不得永久隐藏）
- ?shot 截图模式：页面 JS 检测 location.search 含 shot 时给 html 挂 data-shot 属性（CSS 关闭入场动画直接终态，headless 虚拟时间下动画帧不推进会停在初始帧导致截图空白）、强制全部内容 opacity 1、隐藏模板坞与主题坞，输出纯海报画面
- 页脚署名固定 GENERATED BY AI TEAM（禁止真实团队名/项目名）

## 内容规则

- 要点块 3-5 条：每条 15-30 字，动词开头；超过 5 条合并取舍，不足 3 条向用户再要
- 金句 12-30 字；标题 6-14 字；超长自动截断提示用户改短
- dashboard 模板的 `kpi` 字段写百分比数值字符串（如 "82%"，控制环形图填充与中心数值）；非 dashboard 模板该字段可留默认

## 用户模板内嵌（TPL_DIR，设计专属扩展）

- 用户模板库目录由 user-config.md 的 `TPL_DIR` 指定（auto = `~/.skillforge/user-templates`，Windows 下 `%USERPROFILE%\.skillforge\user-templates`）；目录在技能目录之外，升级技能不覆盖
- 模板文件为 *.html 片段包，三段式注释约定（示例见 `resources/user-template-example.html`）：
  1. `<!--TPL_META-->` 块：`name:` 英文 slug（唯一，禁止与官方 16 个重名）+ `label:` 中文显示名（≤5 字）
  2. `<!--TPL_CSS_BEGIN/END-->` 块：样式，选择器一律 `.tpl-{name}` 开头，颜色只准用 13 主题令牌，禁止写死色值
  3. `<!--TPL_FN_BEGIN/END-->` 块：`TPL['{name}'] = function(){ return '...' }`，可复用 esc()/N(i)/F/DATA
- 生成海报时逐份内嵌进 reference.html 副本四处：CSS 块 → CSS 内嵌点注释前；FN 块 → FN 内嵌点注释后；「我的模板」分组标（多份只插一次）+ 按钮 → 按钮内嵌点注释后；name → TPLS 数组 `'window'` 后
- 约束：name 重名或缺区块的文件跳过并在对话提醒；TPL_DIR 不存在或无 html 文件则跳过内嵌，直接进入三处替换
