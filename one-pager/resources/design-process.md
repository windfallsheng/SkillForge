# 专业设计模式（Pro 七步引导）

> 当用户说「专业设计 / 带我设计 / 从零设计 / 从头到尾设计海报 / 帮我设计一张海报 / 走专业流程」时启用。
> 目标：像资深海报设计师一样，陪用户走完「需求诊断 → 设计决策 → 成品交付」全流程，每步给出专业依据，最终附设计说明。

## 七步流程

### 第 1 步 · 需求诊断（Brief）

用 AskUserQuestion 一次问清四个维度（用户也可直接说「你定」，则按括号内默认走）：

| 维度 | 选项示例 | 默认 |
|:---|:---|:---|
| 用途 | 活动宣传 / 品牌发布 / 内部通知 / 课程讲座 / 招聘 / 邀请 | 活动宣传 |
| 受众 | 职场人 / 学生 / 客户 / 公众 / 专业人群 | 公众 |
| 投放场景 | 朋友圈/群分享 / 打印张贴 / 大屏投影 / 网页头图 | 朋友圈分享 |
| 尺寸比例 | 3:4 竖版（社交海报）/ 1:1 方版 / 16:9 横版（投影） | 3:4 |

产出：一句话设计定位（如「面向职场人的 AI 主题活动宣传海报，社交传播，竖版」）。

### 第 2 步 · 信息架构（Hierarchy）

把内容按视觉重量排四级，一级只许一个：

1. **主标题**（第一视觉，最大字号/最重字重/最前位置）
2. **副标或金句**（第二视觉，承接标题、补足情绪）
3. **要点块**（第三视觉，3-5 条事实信息）
4. **页脚**（第四视觉，日期/地点/署名小字）

产出：层级表（哪级放什么内容、各占画面多少视觉重量）。

### 第 3 步 · 版式决策（Layout）

从 28 套模板中按需求场景推荐 2-3 套并说明理由，用户选定或说「你定」：

| 需求场景 | 推荐组 | 代表模板 |
|:---|:---|:---|
| 品牌/极简/高级感 | 现代主义 | classic / minimal / swiss / window |
| 长文案/多要点 | 编辑出版 | magazine / editorial / typo / newspaper |
| 数据/报告/会议 | 数据商务 | dashboard / grid / timeline / hero |
| 艺术/展览/创意 | 艺术流派 | bauhaus / mondrian / memphis / exhibit / popart / opart / artnouveau |
| 潮牌/青年/夜店/科技 | 先锋实验 | brutalist / acid / glitch / vaporwave / cyber |
| 通知/招聘/邀请/学术 | 场景专用 | academic / recruit / invitation / notice |

产出：选定模板 + 一句话版式依据（为什么这个骨架适配这个场景）。

### 第 4 步 · 配色方案（Color）

从 25 套主题中按「行业 × 情绪」推荐 2-3 套并说明理由：

| 情绪/行业 | 推荐主题 |
|:---|:---|
| 科技/理性/未来 | tech / cyber / violet |
| 商务/可信/正式 | biz / light / classicblue / academic |
| 高端/奢华/质感 | midnight / artdeco / noir / cream |
| 活力/年轻/促销 | pop / coral / retro / memphis |
| 文艺/自然/温和 | morandi / nordic / jade / warm |
| 国风/传统/节庆 | ink / rose |
| 大胆/潮流/先锋 | acid / cyber / memphis / bauhaus |

产出：选定主题 + 一句话配色依据（色相心理/行业惯例/对比度考量）。

### 第 5 步 · 字体情绪（Type）

系统字体栈内选型（零外链纪律不变），只调情绪不引入字体文件：

| 情绪 | 字族方向 | 用法 |
|:---|:---|:---|
| 权威/经典/文艺 | 衬线（宋体/Georgia） | 标题用衬线加情绪，正文无衬线保可读 |
| 现代/极简/科技 | 无衬线（黑体/Helvetica） | 全页无衬线，靠字重（700/900）分层级 |
| 数据/代码/先锋 | 等宽（等宽字体栈） | 数字/标签/页脚用等宽制造机械感 |

产出：标题/正文/页脚三段字族与字重分配方案（以 CSS 描述，实际由所选模板 + 主题令牌落地）。

### 第 6 步 · 视觉焦点（Focal）

确定画面唯一焦点与视觉动线：

- **焦点**：主标题或一个图形元素，用「大小差 + 色彩差 + 位置」三招锁定（焦点元素占画面 1/3 以上视觉重量，色相与背景拉开对比）
- **动线**：竖版走 Z 型（左上→右上→中下），横版走 F 型（左对齐扫读）
- **留白**：焦点四周留呼吸区，密度区（要点块）远离焦点，形成节奏对比

产出：一句话焦点描述（「视觉焦点锁定主标题，Z 型动线收束于底部要点」）。

### 第 7 步 · 交付检查（QA）

生成前对照清单自查，全部通过才落盘：

- 一屏原则：纵向一屏不滚出第二屏
- 层级分明：四级信息一眼可辨，焦点唯一
- 对齐统一：同一轴线上的元素左右对齐，无随机偏移
- 留白充分：页面四边留白 ≥ 内容的呼吸感，不顶边
- 对比达标：正文与背景对比度足够（浅底深字/深底浅字）
- 颜色克制：主色 + 辅色 + 中性色三色体系，无花哨堆色
- 零侵权：系统字体栈、无外链资源、页脚署名 GENERATED BY AI TEAM

## 设计说明（Design Rationale）输出规则

海报生成后，对话中附四段式设计说明（每段 1-2 句，专业口吻）：

1. **设计定位**：这张海报是谁给谁看、在什么场景、达成什么目标
2. **版式依据**：为什么选这套模板（对应七步第 3 步的决策）
3. **配色依据**：为什么选这套主题（对应七步第 4 步的决策）
4. **字体与细节**：字族/字重/焦点/动线的关键设计点

示例：

> **设计定位**：面向职场人的 AI 主题活动宣传海报，社交传播、竖版。
> **版式依据**：选用「经典舞台」，徽章 + 巨字 + 三列卡片结构主次分明，信息密度适中，适配社交分享的远观识别。
> **配色依据**：选用「深蓝科技」，蓝 = 科技信任色，渐变标题增强画面纵深，与「AI」主题语义同频。
> **字体与细节**：标题以 900 字重锁定视觉焦点，Z 型动线收束于底部要点，四周留白保证呼吸感。

## 交互节奏

- 第 1 步必须问（需求不明做不出专业决策）；第 2-6 步每步给推荐 + 理由，用户可确认、改选或说「你定」
- 用户中途改主意（如「颜色换文艺一点」）→ 回到对应步骤重推，其他步骤结论保留
- 全程不生成中间 HTML，七步结论确定后一次性生成最终海报 + 设计说明
